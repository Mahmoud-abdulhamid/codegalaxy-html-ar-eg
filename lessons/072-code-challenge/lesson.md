# HTML Head and Metadata Mastery

المصدر: https://www.w3schools.com/html/html_challenges_head.asp

## مقدمة حول الـ head

مرحبا بكم في درس جديد حول هيكلة صفحات الويب باستخدام HTML والتركيز على قسم head.

- قسم head لا يظهر محتواه مباشرة للمستخدم
- يحتوي على معلومات تقنية هامة للمتصفح
- يعد جزءا أساسيا من هيكل HTML5

## مكونات الـ head الأساسية

تتضمن عناصر head الأساسية title و meta Tags التي تضبط إعدادات الصفحة.

- العنصر title يحدد عنوان الصفحة في المتصفح
- العنصر meta يحدد ترميز الأحرف charset
- العنصر meta يحدد إعدادات العرض viewport

## كتابة هيكل الـ HTML

نبدأ بكتابة هيكل HTML الأساسي مع تعريف DOCTYPE.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
    <meta name="viewport" content="width=device-width">
  </head>
  <body>
    <h1>Welcome</h1>
    <p>Hello World!</p>
  </body>
</html>
```

## إغلاق الـ head وبدء الـ body

نغلق قسم head ونبدأ في كتابة محتوى body المرئي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
    <meta name="viewport" content="width=device-width">
  </head>
  <body>
    <h1>Welcome</h1>
    <p>Hello World!</p>
  </body>
</html>
```

## أفضل الممارسات

التزم دائما بإغلاق Tags بشكل صحيح لضمان سلامة الكود.

- استخدم دائما ترميز UTF-8
- تأكد من وجود title فريد لكل صفحة
- نظم الـ meta Tags في بداية الـ head

## خاتمة الدرس

شكرا لمتابعتكم، استمروا في التدريب وتطبيق ما تعلمتموه اليوم.

- راجع مفاهيم الـ head والـ meta
- طبق التحديات البرمجية المتاحة
- استعد للدرس القادم حول الـ Layout
