# تعلم ألوان HTML وتنسيق الخلفيات والنصوص والحدود

المصدر: https://www.w3schools.com/html/html_colors.asp

## مقدمة ألوان HTML

تحدد ألوان HTML باستخدام أسماء الألوان المعرفة مسبقا أو قيم RGB و HEX و HSL.

- تستخدم الألوان لتحسين المظهر البصري لصفحات الويب
- يدعم متصفح الويب مائة وأربعين اسما قياسيا للألوان
- يمكن تحديد الألوان باستخدام الأسماء أو القيم الرقمية
- تمنحنا أنظمة الألوان مرونة كاملة في التصميم

## تنسيق لون الخلفية

يمكنك ضبط لون خلفية عناصر HTML باستخدام خاصية style ودالة background-color.

```html
<h1 style=
"background-color:
DodgerBlue;">
Hello World
</h1>
```

## تنسيق لون النصوص

تستطيع تغيير لون النصوص مباشرة عبر خاصية color وإعطائها اسم اللون المناسب.

```html
<p style=
"color:
Tomato;">
Lorem ipsum...
</p>
```

## تنسيق حدود العناصر

يمكنك تعيين لون حدود العناصر باستخدام خاصية border مع تحديد السمك والنوع.

```html
<h1 style=
"border:2px
solid
Tomato;">
Hello
</h1>
```

## معاينة النتيجة المرئية

صورة المعاينة توضح ظهور العناصر في المتصفح بالخلفيات والألوان المختلفة.

## قيم الألوان المتقدمة

يمكن تحديد الألوان أيضا باستخدام قيم RGB أو HEX أو HSL للحصول على دقة أكبر.

```html
<h1 style=
"background-color:
rgb(255,
99, 71);">
...</h1>
```

## قنوات الشفافية والـ Alpha

تضيف قيم RGBA و HSLA قناة الشفافية إلى اللون لإنشاء تأثيرات بصرية رائعة.

- تدعم صيغ RGBA و HSLA تحديد نسبة الشفافية
- تتراوح قيمة الشفافية بين الصفر والواحد الصحيح
- تفيد الشفافية في تداخل العناصر والخلفيات
- تعتبر أدوات أساسية للمصممين المحترفين

## خلاصة الدرس

بهذا نكون قد تعرفنا على كافة طرق تلوين العناصر وتنسيقها باحترافية.

- استخدام أسماء الألوان المعرفة مسبقا
- تنسيق الخلفيات والنصوص والحدود بخاصية style
- استخدام القيم الرقمية RGB و HEX
- التحكم بالشفافية عبر RGBA و HSLA
