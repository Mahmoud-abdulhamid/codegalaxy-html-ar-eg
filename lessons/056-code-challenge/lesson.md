# HTML Block and Inline Elements Challenge

المصدر: https://www.w3schools.com/html/html_challenges_blocks.asp

## مقدمة حول عناصر الويب

مرحبا بكم في درس جديد من دورة HTML. اليوم سنتعرف على الفرق بين Block Elements و Inline Elements وكيفية توظيفهما لبناء هيكل منظم للمحتوى.

- فهم طبيعة Block Elements
- استكشاف خصائص Inline Elements
- تطبيق تحديات عملية باستخدام div و span

## القواعد الأساسية للعناصر

تنقسم العناصر في لغة HTML إلى نوعين رئيسيين. العناصر من نوع Block تحجز سطرا كاملا، بينما العناصر من نوع Inline تأخذ فقط مقدار المساحة التي يحتاجها المحتوى.

## استخدام div كعنصر Block

يعد div عنصرا حاويا من نوع Block. نستخدمه لتجميع العناصر معا وتنظيم تخطيط الصفحة، حيث يبدأ كل div في سطر مستقل.

```html
<div>
  <h1>العنوان</h1>
  <p>فقرة نصية</p>
</div>
```

## استخدام span كعنصر Inline

عنصر span هو عنصر من نوع Inline. نستخدمه لتحديد جزء صغير من النص أو تطبيق تنسيقات معينة دون التأثير على تدفق النص العام.

```html
<p>هذا نص <span>مميز</span>
داخل الفقرة.</p>
```

## أفضل الممارسات البرمجية

احرص على استخدام div للهيكلة الكبرى، و span للتعامل مع الأجزاء الدقيقة. هذا التنظيم يسهل عملية التنسيق بـ CSS ويجعل الكود أكثر قابلية للصيانة.

- استخدم div للحاويات الكبيرة
- استخدم span للنصوص المحددة
- حافظ على نظافة الكود
- التزم بالمعايير القياسية

## خاتمة وتحدي

لقد تعلمنا اليوم الفرق بين Block و Inline. أدعوكم لزيارة رابط المصدر في الوصف لتجربة التحديات العملية بنفسكم. مع تحياتي، محمود عبد الحميد.

- راجع مفاهيم Block و Inline
- طبق التحديات في الرابط أدناه
- استمر في ممارسة البرمجة
