# HTML Images Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_images.asp

## مقدمة حول تحديات الصور

مرحبا بكم في درس تحديات الصور في HTML. سنقوم اليوم بتطبيق مهاراتنا البرمجية من خلال حل تحديات عملية لتعزيز فهمنا لعنصر img.

- تعلم كيفية استخدام عنصر img
- فهم دور Attributes في تحديد مسار الصورة
- تطبيق التحديات البرمجية لتعزيز الخبرة
- التركيز على أفضل الممارسات في HTML

## فهم عنصر img

عنصر img هو Empty Element لا يحتاج إلى End Tag. نستخدم src لتحديد المسار و alt لوصف الصورة.

- عنصر img لا يمتلك End Tag
- استخدام src لتحديد مسار ملف الصورة
- استخدام alt لتقديم نص بديل للصورة
- تحسين تجربة المستخدم عبر وصف دقيق

## كتابة كود الصورة

نبدأ بكتابة عنصر img مع تحديد src للرابط و alt للنص البديل.

```html
<img src="image.jpg" 
alt="وصف الصورة هنا">
```

## تفاصيل إضافية للصور

يمكن التحكم في أبعاد الصورة باستخدام width و height لتحسين أداء الصفحة.

```html
<img src="pic.jpg" 
width="500" 
height="300" 
alt="صورة توضيحية">
```

## أفضل الممارسات

تأكد دائما من صحة مسار src واستخدم alt لوصف دقيق يساعد في SEO.

- التحقق من صحة مسار الملف في src
- كتابة نص وصفي ومفيد في alt
- استخدام أبعاد ثابتة لتحسين الأداء
- تجنب ترك alt فارغا في الصور المهمة

## خاتمة وتطبيق عملي

قم بزيارة الرابط في الوصف لتجربة التحديات بنفسك وتطوير مهاراتك.

- راجع مفاهيم img و src و alt
- جرب التحديات البرمجية عبر الرابط
- استمر في ممارسة كتابة الكود
- تابع دورتنا التعليمية للمزيد
