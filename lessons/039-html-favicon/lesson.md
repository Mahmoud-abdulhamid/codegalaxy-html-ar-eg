# HTML Favicon

المصدر: https://www.w3schools.com/html/html_favicon.asp

## مقدمة تعريفية حول Favicon

تعرف على مفهوم Favicon وكيف تظهر بجانب عنوان الصفحة في الـ Web Browser.

- ما هو الـ Favicon وصورته الصغيرة
- أهميته في التمييز بين نوافذ الـ Web Browser
- إضفاء مظهر احترافي لصفحات الويب
- الظهور المجاور لـ title في التاب

## كيفية إنشاء واختيار الـ Favicon

يمكنك استخدام أي صورة أو تصميم واحدة عبر مواقع مثل favicon cc.

- استخدام أي صورة تفضلها كأيقونة
- الاستعانة بمواقع توليد الأيقونات مثل favicon cc
- أهمية البساطة والتباين العالي للصور الصغيرة
- التجهيز السليم لملف الأيقونة

## تخزين وترتيب ملفات الأيقونة

احفظ ملف الأيقونة في الـ root directory أو داخل مجلد images المخصص.

- الحفظ المباشر في الـ root directory
- إنشاء مجلد images وتخزين الملف فيه
- الاسم الشائع للملف هو favicon.ico
- تجهيز مسار الـ Web Server بدقة

## هيكل كود HTML وإضافة الـ link Tag الجزء الأول

نكتب هيكل المستند مع قسم head وعنوان الصفحة داخل title.

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Page 
  Title</title>
```

## إضافة الـ link Tag وخصائص الـ Favicon الجزء الثاني

نستعمل link rel="icon" مع Attributes type و href لربط الأيقونة.

```html
  <link rel="icon" 
        type="image/x-icon" 
        href="/images/favicon.ico">
</head>
<body>
  <h1>This is a Heading</h1>
  <p>This is a paragraph.</p>
</body>
</html>
```

## معاينة النتيجة على المتصفح

تظهر الأيقونة بجانب عنوان الصفحة عند إعادة تحميل المتصفح.

## أفضل الممارسات وخلاصة الدرس

خلاصة الدرس وأفضل الممارسات لتصميم وربط الأيقونات باحترافية.

- استخدام صور واضحة وبسيطة للأيقونات
- التحقق من صحة مسارات الـ href
- مراجعة توثيق الـ link Tag
- التمرن العملي المستمر على الأكواد
