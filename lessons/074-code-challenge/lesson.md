# HTML Layout Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_layout.asp

## مقدمة في هيكلة صفحات الويب

مرحبا بكم في درس اليوم حول بناء هيكل صفحات الويب باستخدام HTML.

- تعلم تنظيم هيكل صفحة الويب
- استخدام العناصر الدلالية في HTML5
- تطبيق تحدي برمجي عملي

## المفاهيم الأساسية للهيكل

نستخدم عناصر مثل header و nav و section و footer لتنظيم محتوى الصفحة.

- استخدام header للترويسة
- استخدام nav للقوائم
- استخدام section للمحتوى
- استخدام footer للتذييل

## كتابة هيكل الصفحة الجزء الأول

نبدأ بكتابة الكود الأساسي مع تعريف DOCTYPE وفتح العناصر الرئيسية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Layout</title>
  </head>
  <body>
    <header>
      <h1>My Page</h1>
    </header>
    <nav>Link</nav>
    <section>
      <p>Main Content</p>
    </section>
    <footer>
      <p>Footer</p>
    </footer>
  </body>
</html>
```

## استكمال هيكل الصفحة

نضيف عناصر nav و section لتنظيم الروابط والمحتوى الرئيسي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Layout</title>
  </head>

```

## أفضل الممارسات البرمجية

احرص دائما على إغلاق العناصر بشكل صحيح وتنسيق الكود بوضوح.

- إغلاق جميع العناصر بشكل صحيح
- استخدام المسافات البادئة للتنظيم
- كتابة كود نظيف وسهل القراءة

## خاتمة الدرس

شكرا لمتابعتكم، جربوا التحدي بأنفسكم عبر الرابط في الوصف.

- راجع مفاهيم HTML Layout
- قم بحل التحدي البرمجي
- استمر في ممارسة البرمجة
