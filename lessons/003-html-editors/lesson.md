# HTML Editors

المصدر: https://www.w3schools.com/html/html_editors.asp

## خرافة البرامج المعقدة

هل تحتاج برامج معقدة لكتابة HTML؟ الحقيقة هي أنك تحتاج فقط لـ Text Editor بسيط.

- خرافة: البرامج المعقدة ضرورية للمبتدئين
- الحقيقة: المتصفح يحتاج فقط كود HTML منظم
- الهدف: استخدام Text Editor بسيط للتعلم
- النتيجة: فهم أعمق لهيكل الصفحة

## ليه بنستخدم Text Editor بسيط؟

لماذا نفضل استخدام Text Editor بسيط؟

- التركيز الكامل على كتابة الكود يدويا
- تجنب الاعتماد على ميزات الإكمال التلقائي
- حفظ الـ Tags وفهم هيكل الصفحة
- بناء أساس قوي للمستقبل

## إعداد Notepad على Windows

خطوات فتح Notepad على أنظمة Windows

- Windows 8+: افتح Start Screen واكتب Notepad
- Windows 7 أو أقدم: Start > Programs > Accessories > Notepad
- أداة خفيفة وسريعة للبدء فورا

## إعداد TextEdit على Mac

ضبط إعدادات TextEdit للعمل مع HTML

- افتح Finder > Applications > TextEdit
- في Preferences > Format اختر Plain Text
- فعل خيار Display HTML files as HTML code
- الآن أنت جاهز لكتابة الكود

## كتابة أول كود HTML

كتابة الكود الأساسي في الـ Text Editor

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>
```

## حفظ وتشغيل الملف

حفظ الملف بترميز UTF-8 وتشغيله في المتصفح

```text
File Name: index.html
Encoding: UTF-8
Extension: .html or .htm
```
