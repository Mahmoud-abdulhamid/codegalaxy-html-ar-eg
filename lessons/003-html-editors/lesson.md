# HTML Editors

المصدر: https://www.w3schools.com/html/html_editors.asp

## مقدمة حول HTML Editors

تعرف على كيفية استخدام Text Editors في كتابة وتطوير صفحات الويب بكفاءة.

- أهمية استخدام Text Editor بسيط لتعلم HTML
- الفرق بين Notepad في نظام PC و TextEdit في نظام Mac
- خطوات إنشاء وحفظ أول ملف ويب

## اختيار Text Editor المناسب

ننصح باستخدام Notepad أو TextEdit البسيط لتعلم لغة HTML.

- استخدام Notepad لنظام التشغيل Windows
- استخدام TextEdit لنظام التشغيل Mac
- تجنب المحررات المعقدة في بداية التعلم

## فتح Notepad على نظام Windows

افتح برنامج Notepad على نظام Windows من خلال قائمة ابدأ.

- افتح Start Screen في نظام Windows 8 أو أحدث
- اكتب كلمة Notepad في خانة البحث
- في الإصدارات القديمة اختر من Accessories

## ضبط إعدادات TextEdit لنظام Mac

اضبط إعدادات TextEdit على Mac ليحفظ الملفات بصيغة Plain Text.

- انتقل إلى Finder ثم Applications ثم TextEdit
- اختر Plain Text من لوحة Preferences
- فعل خيار عرض ملفات HTML كأكواد حقيقية

## كتابة أول كود HTML

اكتب الكود الأساسي الذي يحتوي على DOCTYPE وعناصر h1 و p داخل body.

```html
<!DOCTYPE html>
<html>
<body>
<h1>My First Heading</h1>
<p>My first paragraph.</p>
</body>
</html>
```

## حفظ ملف HTML بالطريقة الصحيحة

احفظ الملف باسم index.htm مع تعيين الترميز إلى UTF-8.

- اختر File ثم Save as في قائمة البرنامج
- احفظ الملف باسم index.htm أو index.html
- حدد ترميز الحروف إلى UTF-8 المفضل لملفات الويب

## معاينة الصفحة في Web Browser

افتح الملف المحفوظ في متصفح الويب لمشاهدة النتيجة النهائية.

## استخدام W3Schools Online Editor

استخدم محررات الإنترنت التفاعلية لتجربة الأكواد بسرعة ومشاركة النتائج.

```html
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>
<h1>This is a Heading</h1>
<p>This is a paragraph.</p>
</body>
</html>
```

```text
This is a Heading
This is a paragraph.
```

## خلاصة الدرس والدعوة للتطبيق

خلاصة الدرس: استخدم أدوات بسيطة لكتابة ملفات HTML ومعاينتها في المتصفح.

- استخدام Text Editors يرسخ فهم بنية الكود
- أهمية الحفظ بصيغة UTF-8 لتجنب مشاكل الرموز
- تجربة الأكواد فورا عبر Web Browser
