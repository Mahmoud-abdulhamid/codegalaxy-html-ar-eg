# محررات أكواد HTML وكيف تبدأ كتابة كودك الأول

المصدر: https://www.w3schools.com/html/html_editors.asp

## صدمة الملف العطلان ومحررات الأكواد

عمرك كتبت كود HTML وفتحته في الـ Web Browser ولقيت الكود طالع قدامك زي ما هو كنص عطلان بدل صفحة حقيقية؟ الصداع ده بيحصل للمبتدئين عشان بيستخدموا برامج Rich Text زي Word بتدس رموز مخفية، أو بيسيبوا امتداد .txt شغال من غير ما يأخذوا بالهم، فيضيع مجهودهم كله على الفاضي! المتصفح محتاج نص خام تماما Plain Text يفهمه مباشرة من غير أي تنسيقات غريبة تفسد بنية الـ Tags. اليوم سنفك شفرة الأساس ده خطوة بخطوة، وهنتعلم إزاي نستخدم محرر نصوص بسيط زي Notepad و TextEdit ونضبط الـ Encoding صح عشان صفحتك تشتغل بنجاح من أول كليك.

- ظهور كود HTML كنص خام بسبب امتداد .txt الخفي
- تدمير الـ Tags البرمجية بواسطة معالجات النصوص Rich Text
- أهمية استخدام محرر Plain Text نظيف في بداية التعلم
- ضبط إعدادات الحفظ الصحيحة وترميز UTF-8 المعياري

## مخطط مسار بناء ملف HTML من المحرر إلى المتصفح

عشان نفهم كواليس اللي بيحصل تحت الكبوت في جهازك، انظر معي إلى هذا المخطط. العملية تبدأ من خطوة 1 لما تفتح محرر نصوص بسيط وتكتب جواه الـ Tags كنص خام تماما من غير أي زوائد. في خطوة 2، تعمل Save للملف باسم واضح وتحدد الامتداد .html، والنقطة الحاسمة هنا إنك تختار ترميز UTF-8 عشان المتصفح يقرأ الحروف العربية والإنجليزية بدون أي تشوه. وأخيرا في خطوة 3، تفتح الملف جوه الـ Web Browser، المحرك هنا يقرأ الكود ويبني شجرة الـ DOM عشان يعرض لك عناصر الصفحة الحقيقية بشكل مرئي سليم وسريع.

## كتابة أول كود HTML في محرر النصوص

يلا بينا نكتب أول كود حقيقي في المحرر. السطر 1 يبدأ بـ DOCTYPE html عشان يعرف الـ Web Browser إننا شغالين على أحدث معايير HTML5. بعدها نفتح Tag الـ html في السطر 2 وده الحاوية الكبرى، وجواه في السطر 3 نضع قسم <body> body. ركز في السطر 4 و 5، هنا أضفنا عنوانا رئيسيا باستخدام Tag h1 وفقرة نصية بـ Tag p، مع إغلاق كل Tag يدويا بالـ Slash. كتابتك للأكواد دي بيدك من غير إكمال تلقائي تبني ذاكرتك العضلية وتجعلك فاهما لتفاصيل كل سطر في بنية صفحتك.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>
```

## مقارنة شاملة بين محررات النصوص البسيطة وبيئات التطوير

السؤال الهندسي اللي دايما بنسأله: ليه W3Schools تنصح بـ Notepad أو TextEdit ونحن لدينا بيئات متطورة زي VS Code؟ هذا الجدول يوضح لك المفاضلة الحقيقية. المحررات البسيطة تفتقر للـ Syntax Highlighting والـ Auto-complete، وده بالضبط ميزتها التعليمية الأولى! لما تكتب كل حرف بنفسك، الذاكرة العضلية عندك تثبت وتحفظ الـ Tags من غير أن تعتمد على أدوات مساعدة. لكن في مشاريع العمل الكبيرة، نذهب فورا لبيئات التطوير المتقدمة عشان الإنتاجية والـ Extensions، فابدأ بسيطا في أول أسبوع وبعدين انطلق للمحررات الاحترافية.

## ضبط ترميز الملف وعنوان الصفحة في Head

إضافة عنصر head لضبط ترميز الحروف UTF-8 وعنوان الصفحة title وتحديد لغة المحتوى عبر lang.

```html
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
  </head>
  <body>
    <h1>مرحبا بك في عالم الويب</h1>
    <p>تم حفظ هذا الملف بترميز UTF-8 سليم.</p>
  </body>
</html>
```

## كواليس حفظ الملفات: Plain Text مقابل Rich Text

الفارق الهيكلي في معالجة الذاكرة بين بايتات Plain Text الخام وملفات Rich Text المشبعة بالتنسيقات الثنائية.

## منحنى سرعة التعلم وإنتاجية المطور عبر المحررات

مقارنة نسب استيعاب المفاهيم للمبتدئين بين المحررات البسيطة والمحررات المتقدمة ذات الإكمال التلقائي.

## التوافقية وإمكانية الوصول مع إعدادات المحرر

أهمية إعدادات الترميز ونهايات الأسطر وتحديد لغة الصفحة لضمان توافقية الأنظمة وأدوات الوصول.

- ترميز UTF-8 الإلزامي لدعم قراءة Screen Readers للحروف بدقة 100
- فهم فوارق Line Endings بين Windows CRLF وأنظمة Mac و Linux LF
- ضبط Attribute الـ lang لتوجيه محركات النطق الصوتي ومعالجة النصوص
- تجنب حفظ الملفات بصيغ ثنائية لضمان التوافقية عبر كافة بيئات التشغيل

## أفخاخ شائعة في بيئة العمل وكيفية تجنبها

3 أخطاء شائعة عند حفظ الملفات: فخ الامتداد المخفي index.html.txt، مشاكل علامات التنصيص Smart Quotes في Mac، وتأثير ترميز ANSI الخاطئ مقارنة مع UTF-8.

- فخ الامتداد المزدوج index.html.txt وضرورة تفعيل File Name Extensions في نظام التشغيل
- مشكلة Smart Quotes في تطبيق TextEdit وتحويل علامات التنصيص البرمجية لشكل جمالي تالف
- تجنب ترميز ANSI الافتراضي في بعض المحررات واعتماد UTF-8 لضمان سلامة المحتوى العربي

## المشروع المتكامل: صفحة ويب احترافية مع تنسيق CSS مدمج

تجميع بنية HTML5 المتكاملة مع ستايل CSS مدمج داخل ملف واحد وعرض الكارت المنسق في المتصفح.

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8">
    <title>صفحة متكاملة</title>
    <style>
      body {
        font-family: sans-serif; background: #f8fafc; padding: 40px; margin: 0;
      }
      .card {
        background: #ffffff; border: 1px solid #e2e8f0;
        border-radius: 8px; padding: 24px; max-width: 480px; margin: 0 auto;
      }
      h1 {
        color: #0f172a; font-size: 22px; margin-top: 0;
      }
      p {
        color: #475569; line-height: 1.6; margin-bottom: 0;
      }
    </style>
  </head>
  <body>
    <div class="card">
      <h1>أول صفحة ويب متكاملة</h1>
      <p>كتبنا هذه الصفحة يدويًا باستخدام محرر نصوص بسيط مع تنسيق CSS مدمج.</p>
    </div>
  </body>
</html>
```

ملخص المهارات الأساسية لمحررات HTML وتحدي كتابة أول كارت تعريفي متكامل يدويا.

- القاعدة الذهبية: محرر Plain Text بسيط مع امتداد .html سليم وترميز UTF-8
- الاستفادة من أدوات الاختبار السريع مثل W3Schools Tryit Editor لمعاينة وتجربة الأكواد
- تحدي الدرس العملي: أنشئ صفحة كارت تعريفي يحتوي على عنوان وفقرة ورابط وافتحها بالمتصفح
