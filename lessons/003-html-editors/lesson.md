# شرح محررات النصوص وكيفية كتابة وحفظ صفحات HTML

المصدر: https://www.w3schools.com/html/html_editors.asp

## مقدمة محررات النصوص

مرحبا بكم في درس محررات النصوص وكيفية كتابة وتشغيل صفحات HTML.

- نحتاج إلى محرر نصوص بسيط لتعلم لغة HTML
- يمكن إنشاء وتعديل صفحات الويب عبر HTML editors
- استخدام Text editor بسيط هو الطريقة الأفضل للتعلم

## اختيار المححر المناسب

ننصح باستخدام Notepad أو TextEdit البسيط لتعلم لغة HTML بefاعلية.

- تفضيل برامج النصوص البسيطة على المحررات المعقدة للمبتدئين
- برنامج Notepad المخصص لأجهزة PC
- برنامج TextEdit المخصص لأجهزة Mac

## فتح برنامج Notepad

خطوات فتح برنامج Notepad على أجهزة الكمبيوتر لنظام Windows.

- فتح Start Screen وكتابة Notepad في نظام Windows 8 وما بعده
- الوصول عبر Start ثم Programs ثم Accessories في الإصدارات القديمة
- تجهيز بيئة العمل لكتابة كود HTML الأول

## فتح وتعديل إعدادات TextEdit

خطوات فتح وتعديل تفضيلات برنامج TextEdit على أجهزة Mac.

- الانتقال عبر Finder ثم Applications ثم TextEdit
- اختيار Plain Text من قسم Preferences ثم Format
- تفعيل خيار عرض ملفات HTML كأكواد برمجية

## كتابة أول كود HTML

كتابة الهيكل الأساسي الأول لصفحة الويب داخل محرر النصوص.

```html
<!DOCTYPE html>
<html>
<body>
<h1>My First Heading</h1>
<p>My first paragraph.</p>
</body>
</html>
```

## حفظ ملف HTML

حفظ الملف بامتداد .htm أو .html وتحديد ترميز UTF-8.

- اختيار File ثم Save as من قائمة محرر النصوص
- تسمية الملف index.htm أو index.html
- ضبط الترميز على UTF-8 كأفضل ممارسة لملفات الويب

## معاينة الصفحة في المتصفح

فتح ملف HTML المحفوظ داخل متصفح الويب لمعاينة النتيجة النهائية.

## محرر W3Schools المباشر

استخدام محرر W3Schools Online Editor لتجربة الأكواد بشكل فوري.

```html
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>
<h1>This is a Heading</h1>
<p>This is a paragraph.</p>
</body>
</html>
```

```text
This is a Heading
This is a paragraph.
```

## خلاصة الدرس والممارسات

خلاصة الدرس: أهمية استخدام محررات النصوص البسيطة لتطوير مهارات لغة HTML.

- استخدام Text editors بسيطة يسرع عملية تعلم لغة HTML
- أهمية تحديد ترميز UTF-8 للملفات
- إمكانية استخدام W3schools Spaces لحفظ وتطوير المواقع أونلاين
