# HTML HSL and HSLA Colors

المصدر: https://www.w3schools.com/html/html_colors_hsl.asp

## مقدمة ألوان HSL

تعرف على نظام HSL لتحديد الألوان في صفحات الويب.

- نظام HSL يمثل Hue و Saturation و Lightness
- يوفر طريقة بديلة وأكثر مرونة لتحديد الألوان
- يدعم قناة الشفافية Alpha من خلال نظام HSLA

## قاعدة HSL الأساسية

الصيغة الأساسية لاستخدام دالة hsl في تنسيق عناصر الويب.

```css
background-color: hsl(0, 100%, 50%);
```

## شرح قيمة Hue

Hue يحدد زاوية اللون على عجلة الألوان من 0 إلى 360 درجة.

- 0 درجة تمثل اللون الأحمر
- 120 درجة تمثل اللون الأخضر
- 240 درجة تمثل اللون الأزرق

## شرح قيمة Saturation

Saturation تعبر عن درجة كثافة ونقاء اللون بنسبة مئوية.

- 100 بالمائة تعني لونا نقيا كاملا
- 50 بالمائة تعني لونا باهتا جزئيا
- 0 بالمائة تعني لونا رماديا بالكامل

## شرح قيمة Lightness

Lightness تتحكم في سطوع اللون من الأسود إلى الأبيض.

- 0 بالمائة تعني اللون الأسود تماما
- 50 بالمائة تعني الإضاءة العادية للون
- 100 بالمائة تعني اللون الأبيض التام

## الدرجات الرمادية Shades of Gray

تحديد تدرجات الرمادي بتثبيت Hue و Saturation على صفر.

```css
background-color: hsl(0, 0%, 50%);
```

## استخدام نظام HSLA

نظام HSLA يضيف قناة Alpha للتحكم في شفافية العناصر.

```css
background-color: hsla(0, 100%, 50%, 0.5);
```

## خلاصة الدرس

خلاصة استخدام أقسام HSL و HSLA لتنسيق صفحات الويب.

- استخدام HSL لتحديد الألوان بدقة عبر Hue و Saturation و Lightness
- ضبط درجات الرمادي عبر تصفير Hue و Saturation
- إضافة الشفافية للعناصر عبر قناة Alpha في نظام HSLA
