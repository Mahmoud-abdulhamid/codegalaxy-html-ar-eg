# HTML HEX and HEXA Colors

المصدر: https://www.w3schools.com/html/html_colors_hex.asp

## مقدمة في ألوان HEX

نظام الألوان HEX يعتمد على القيم السداسية عشرية لتمثيل الألوان في صفحات الويب.

- نظام HEX يستخدم قيم #RRGGBB
- RR يمثل اللون الأحمر
- GG يمثل اللون الأخضر
- BB يمثل اللون الأزرق

## هيكل قيم HEX

تتراوح قيم HEX بين 00 و FF لتمثيل شدة كل لون أساسي.

```css
/* أمثلة على قيم HEX */
color: #ff0000; /* أحمر خالص */
color: #00ff00; /* أخضر خالص */
color: #000000; /* اللون الأسود */
color: #ffffff; /* اللون الأبيض */
```

## درجات اللون الرمادي

تتساوى قيم R و G و B لإنتاج درجات اللون الرمادي.

```css
/* درجات الرمادي */
color: #333333; /* رمادي داكن */
color: #888888; /* رمادي متوسط */
color: #cccccc; /* رمادي فاتح */
```

## مفهوم HEXA و Alpha

نظام HEXA يضيف قناة Alpha للتحكم في شفافية اللون.

- الصيغة: #rrggbbaa
- aa يمثل قناة Alpha
- 00 تعني شفافية كاملة
- FF تعني غير شفاف تماما
- 80 تعني شفافية بنسبة 50

## تطبيق عملي على HEXA

استخدام HEXA مع قيمة 80 يمنح شفافية بنسبة 50.

```css
/* مثال على HEXA */
/* أحمر مع شفافية 50% */
color: #ff000080;
```

## خلاصة الدرس

مارسوا كتابة قيم HEX و HEXA لتتقنوا التحكم في ألوان صفحاتكم.

- HEX يستخدم 6 خانات للألوان
- HEXA يستخدم 8 خانات مع Alpha
- القيم بين 00 و FF
- جربوا الأكواد بأنفسكم
