# HTML Links - Different Colors

المصدر: https://www.w3schools.com/html/html_links_colors.asp

## مقدمة ألوان الروابط في HTML

تعرض روابط HTML بألوان مختلفة اعتمادا على ما إذا تم زيارتها أو لم تزر بعد.

- تتغير ألوان الروابط حسب حالة التفاعل
- الروابط غير المزارعة تسمى unvisited
- الروابط المزارعة تسمى visited
- الروابط النشطة تسمى active

## مفهوم حالات الروابط و CSS

يمكننا تغيير ألوان حالات الروابط الافتراضية باستخدام قواعد CSS المخصصة.

- المتصفحات توفر ألوانا افتراضية للروابط
- نستخدم CSS لتعديل مظهر الروابط بالكامل
- نستهدف الحالات المختلفة للرابط بـ pseudo-classes

## كود تنسيق الرابط غير المزارع والمزارع

نحدد لون الأخضر للرابط العادي والوردي للرابط المزارع بدون خط تحتي.

```html
<style>
a:link {
  color: green;
  text-decoration: none;
}
a:visited {
  color: pink;
  text-decoration: none;
}
</style>
```

## كود تأثيرات المرور والحالة النشطة

نستخدم a:hover لتغيير اللون إلى الأحمر و a:active إلى الأصفر عند النقر.

```html
<style>
a:hover {
  color: red;
  text-decoration: underline;
}
a:active {
  color: yellow;
  text-decoration: underline;
}
</style>
```

## معاينة ألوان الروابط المتعددة

صورة المعاينة تظهر تأثير الألوان المختلفة للروابط حسب حالتها في المتصفح.

## تحويل الروابط إلى أزرار احترافية

يمكننا تصميم الروابط لتظهر كأزرار تفاعلية جميلة باستخدام خصائص CSS.

```html
<style>
a:link, a:visited {
  background-color: #f44336;
  color: white;
  padding: 15px 25px;
  text-align: center;
  display: inline-block;
}
</style>
```

## معاينة أزرار الروابط المصممة

صورة المعاينة توضح شكل الرابط بعد تحويله إلى زر ملون وجذاب.

## خلاصة الدرس وأهم الممارسات

تعلمنا في هذا الدرس التحكم بألوان الروابط وتصميم الأزرار باستخدام CSS.

- استخدام pseudo-classes لتنسيق الحالات
- التحكم الكامل بألوان النصوص والخلفيات
- تحويل الروابط التقليدية إلى أزرار تفاعلية
- مراجعة مرجع HTML Tag Reference للمزيد
