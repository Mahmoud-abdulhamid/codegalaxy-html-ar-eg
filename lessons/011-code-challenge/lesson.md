# HTML Headings Hierarchy Challenge

المصدر: https://www.w3schools.com/html/html_challenges_headings.asp

## مقدمة في HTML Headings

مرحبا بكم في درس HTML Headings. سنتعلم اليوم كيفية تنظيم المحتوى باستخدام عناصر العناوين لتحسين هيكل الصفحة.

- تستخدم Headings لتنظيم المحتوى هرميا
- تتراوح من h1 كأهم عنوان إلى h6 كأقلها أهمية
- تساعد محركات البحث في فهم محتوى الصفحة
- تسهل على المستخدمين قراءة النصوص الطويلة

## التدرج الهرمي للعناوين

تتكون عناصر Headings من ستة مستويات تبدأ من h1 كعنوان رئيسي وتتدرج في الأهمية حتى h6.

## كتابة الكود البرمجي

نكتب العناوين باستخدام Start Tag و End Tag داخل قسم body لضمان ظهورها بشكل صحيح.

```html
<body>
  <h1>العنوان الرئيسي</h1>
  <h2>عنوان فرعي</h2>
  <h3>عنوان جانبي</h3>
</body>
```

## أفضل الممارسات

التزم بالترتيب المنطقي للعناوين ولا تستخدمها فقط لتغيير حجم الخط، بل لبناء هيكل الصفحة.

- استخدم h1 مرة واحدة فقط في الصفحة
- حافظ على الترتيب المتسلسل للعناصر
- استخدم CSS لتنسيق حجم الخط وليس Headings
- اجعل العناوين وصفية ومختصرة

## تحدي البرمجة

اختبر مهاراتك في ترتيب العناوين عبر تحدي البرمجة المتاح في موقع W3Schools.

- قم بزيارة رابط التحدي في الأسفل
- طبق ما تعلمته عن h1 إلى h6
- تحقق من صحة الكود الخاص بك
- استمر في الممارسة لتعزيز فهمك

## خاتمة الدرس

شكرا لمتابعتكم. لقد أتممنا فهم أساسيات العناوين في HTML. استمروا في التدريب والممارسة.

- راجع مفاهيم h1 إلى h6
- طبق التحدي البرمجي المذكور
- استعد للدرس القادم حول Paragraphs
- تابع دورة HTML على CodeGalaxy
