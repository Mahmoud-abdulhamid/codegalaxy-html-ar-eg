# HTML Lists Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_lists.asp

## مقدمة تحدي القوائم

مرحبا بكم في درس تحدي القوائم في لغة HTML وكيف نختبر مهاراتنا البرمجية.

- مرحبا بكم في تحدي لغة HTML الجديد
- التركيز على القوائم البرمجية Ordered و Unordered
- اختبار المهارات العملية لإنشاء الـ Lists

## مفهوم القوائم المرتبة وغير المرتبة

نحتاج في تصميم صفحات الويب إلى استخدام القوائم بنوعيها المرتبة وغير المرتبة.

- استخدام الـ Lists لتنظيم وترتيب محتوى صفحات الويب
- القوائم غير المرتبة تستخدم الـ Tags المناسبة
- القوائم المرتبة تنظم العناصر بأرقام تسلسلية واضحة

## كتابة هيكل القوائم البرلمجي

شرح هيكل القوائم البرمجي وكيفية كتابة الـ Elements و Tags داخل المستند.

```html
<ul>
  item one
  item two
</ul>
```

## استكمال تفاصيل عناصر القائمة

نستخدم الـ Tags المناسبة داخل القائمة لضمان ظهور العناصر بشكل منظم في المتصفح.

```html
<ol>
  <li>First item</li>
  <li>Second item</li>
</ol>
```

## معاينة المخرجات في متصفح الويب

كيف تظهر عناصر القوائم عند تشغيل الكود وتصفحه في متصفحات الويب المختلفة.

- عرض القوائم المرتبة وغير المرتبة في Web Browser
- التحقق من صحة الـ Tags وتنفيذ التحدي بنجاح
- تجربة الأكواد بأنفسكم لضمان استيعاب المفهوم بالكامل

## أفضل الممارسات البرمجية للتحدي

أهم الممارسات البرمجية لكتابة الـ Tags والـ Elements بطريقة صحيحة وخالية من الأخطاء.

- حرص المطور على إغلاق كافة الـ Tags بإتقان
- التأكد من توافق الأكواد مع معايير HTML الحديثة
- اختبار التحديات البرمجية بشكل دوري لتثبيت المعلومة

## خلاصة الدرس ودعوة للتطبيق

خلاصة درس تحدي القوائم في لغة HTML مع دعوة لمواصلة التطبيق العملي للبرمجة.

- إنهاء تحدي القوائم البرمجية في لغة HTML بنجاح
- مراجعة دورية لجميع مفاهيم الـ Lists والـ Elements
- تابعوا الدروس القادمة لتطوير مهاراتكم في تطوير الويب
