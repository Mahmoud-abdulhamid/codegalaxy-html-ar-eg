# تعلم كيفية مسح محتوى حقل الإدخال في لغة HTML

المصدر: https://www.w3schools.com/howto/howto_html_clear_input.asp

## مقدمة الدرس

مرحبا بكم في درس تعلم كيفية مسح محتوى حقل الإدخال في لغة HTML بطرق عملية.

- تعلم كيفية تفريغ حقل الإدخال تلقائيا
- استخدام حدث onfocus مع عناصر الإدخال
- استخدام زر خارجي للتحكم في القيمة

## المفاهيم الأساسية

نحتاج أحيانا لتفريغ حقل الإدخال بمجرد النقر عليه لتسهيل إدخال البيانات.

- أهمية مسح حقل الإدخال لتجربة مستخدم أفضل
- دور حدث onfocus في التفاعل المباشر
- تحديث خاصية القيمة برمجيا

## كود الحدث onfocus

شاهد معنا هذا المثال البرمجي الأول لاستخدام حدث onfocus.

```html
<input
  type="text"
  onfocus="this.value=''"
  value="Blabla">

```

## شرح تفاصيل الكود الأول

تشير كلمة this إلى العنصر الحالي بينما تقوم value بتفريغ النص.

- تحديد نوع الحقل باستخدام type text
- استخدام this للإشارة إلى الحقل نفسه
- تعيين قيمة فارغة عند التركيز

## مثال استخدام الزر

ننتقل إلى طريقة أخرى وهي استخدام زر خارجي لمسح القيمة.

```html
<button
  onclick="
    document
      .getElementById('myInput')
      .value = ''
  ">
  Clear input
</button>
```

## عنصر الإدخال المرتبط بالزر

نربط الزر مع عنصر input يحمل معرفا فريدا باسم myInput.

```html
<input
  type="text"
  value="Blabla"
  id="myInput">

```

## أفضل الممارسات

احرص على استخدام المعرفات الفريدة لتجنب الأخطاء البرمجية.

- استخدام المعرفات الفريدة id بحذر
- اختبار النماذج على متصفحات الويب المختلفة
- الالتزام بمعايير لغة HTML5

## خاتمة الدرس

تعرفنا اليوم على طرق مسح حقل الإدخال وننتظركم في الدرس القادم.

- ملخص شامل لمسح حقول الإدخال
- أهمية التفاعل البرمجي في النماذج
- تابعونا للمزيد من دروس الويب المتقدمة
