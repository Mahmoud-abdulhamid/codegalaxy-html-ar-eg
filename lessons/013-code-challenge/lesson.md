# HTML Paragraphs Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_paragraphs.asp

## مقدمة تحدي فقرات HTML

مرحبا بكم في درس جديد لاختبار مهارات فقرات HTML وتطبيق التحديات البرمجية بأسلوب عملي.

- اختبار المهارات في لغة HTML
- التركيز على فقرات النصوص والعناصر
- تطبيق التحديات البرمجية بشكل عملي

## فهم تحدي الفقرات

يتيح لنا التحدي اختبار استيعاب فقرات HTML وكيفية تنسيق النصوص باستخدام Tags المناسبة.

- تقييم الفهم الحقيقي لـ Paragraphs
- استخدام Tag p لتنظيم النصوص
- تحسين بنية صفحات الويب وتنسيقها

## كتابة هيكل التحدي البرمجي

هيكل الكود الأساسي لحل التحدي مع تعريف DOCTYPE وتجهيز عناصر المستند.

```html
<!DOCTYPE html>
<html>
<head>
<title>Challenge</title>
</head>
<body>
```

## إضافة فقرات النصوص

إضافة فقرات النصوص باستخدام Tag p لتنظيم محتوى صفحة الويب.

```html
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
```

## استخدام Breaks والنصوص المنسقة

استخدام Tag br لإضافة سطر جديد واستخدام pre للنصوص المنسقة مسبقا.

```html
<p>First line<br>Second line</p>
<pre>Preformatted text</pre>
```

## إنهاء وتغليف هيكل الصفحة

إغلاق Tags body و html لإنهاء صفحة الويب البرمجية بشكل صحيح.

```html
</body>
</html>
```

## أفضل الممارسات البرمجية

أفضل الممارسات تشمل إغلاق Tags بانتظام وكتابة أكواد نظيفة ومنظمة.

- الالتزام بإغلاق كل Start Tag بـ End Tag
- الحفاظ على تنسيق الأسطر والمسافات البادئة
- مراجعة الكود قبل تنفيذه في المتصفح

## خلاصة الدرس ودعوة للتجربة

خلاصة الدرس مع دعوة لتجربة الأكواد بأنفسكم من خلال الرابط في الوصف.

- إتمام التحدي بنجاح وتطبيق عملي شامل
- تجربة الأكواد من الرابط في الوصف
- انتظار الدرس القادم لاستكمال دورة HTML
