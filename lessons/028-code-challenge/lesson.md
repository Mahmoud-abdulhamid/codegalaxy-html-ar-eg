# تحدي البرمجة في HTML و CSS

المصدر: https://www.w3schools.com/html/html_challenges_css.asp

## مقدمة في تحديات HTML و CSS

أهلا بكم في درس تحدي البرمجة لدمج CSS مع HTML.

- تحدي مهارات HTML و CSS
- استخدام Internal Style Sheet
- تطبيق التنسيقات داخل ملف HTML
- تحسين مظهر عناصر الويب

## مفهوم Internal Style Sheet

نستخدم عنصر style داخل head لتعريف التنسيقات.

- استخدام <style> داخل <head>
- كتابة CSS مباشرة في ملف HTML
- فصل التنسيق عن هيكل الصفحة
- سهولة التحكم في مظهر العناصر

## هيكل الكود الأساسي

الهيكل الأساسي لملف HTML مع عنصر style.

```html
<!DOCTYPE html>
<html>
<head>
<style>
body {background: blue;}
</style>
</head>
<body>
<h1>Hello</h1>
</body>
</html>
```
