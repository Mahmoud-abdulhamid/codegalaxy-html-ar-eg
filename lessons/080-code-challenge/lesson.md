# HTML Semantic Elements and Layout

المصدر: https://www.w3schools.com/html/html_challenges_semantics.asp

## مقدمة في لغة HTML

مرحبا بكم في درس اليوم حول أهمية Semantic Elements في بناء هيكل صفحة الويب بشكل احترافي ومنظم.

- لغة HTML هي حجر الأساس لبناء صفحات الويب
- استخدام Semantic Elements يسهل فهم هيكل الصفحة
- التنظيم الجيد للكود يرفع من جودة الموقع

## تعريف المستند DOCTYPE

يبدأ كل مستند HTML بتعريف <!DOCTYPE html> لإخبار المتصفح باستخدام معايير HTML5 الحديثة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>Hello World</h1>
    <p>Styled Web Page</p>
  </body>
</html>
```

## قسم الـ head

يحتوي قسم head على معلومات تقنية مثل title الذي يظهر في شريط عنوان المتصفح.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
  </head>
  <body>
    <h1>عنوان رئيسي</h1>
    <p>هذه فقرة نصية.</p>
  </body>
</html>
```

## قسم الـ body

قسم body هو المكان المخصص لكتابة المحتوى المرئي الذي يظهر للمستخدم مثل العناوين والفقرات.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
  </head>
  <body>
    <h1>عنوان رئيسي</h1>
    <p>هذه فقرة نصية.</p>
  </body>
</html>
```

## مفهوم الـ Tags و Elements

يتكون الـ Element من Start Tag و End Tag والمحتوى الموجود بينهما.

- مفهوم Start Tag: Start Tag
- مفهوم End Tag: End Tag
- Content: المحتوى بين الوسمين
- Element: المجموع الكامل للوسوم والمحتوى

## أفضل الممارسات

احرص دائما على إغلاق Tags بشكل صحيح واستخدام العناصر الدلالية لجعل الكود نظيفا وقابلا للصيانة.

- أغلق جميع Tags المفتوحة
- استخدم العناصر الدلالية دائما
- حافظ على تنسيق الكود بمسافات بادئة
- راجع الكود دوريا للتأكد من خلوه من الأخطاء

## خاتمة الدرس

شكرا لمتابعتكم، لا تنسوا تجربة الأكواد بأنفسكم عبر الرابط في الوصف.

- راجع الرابط في الوصف للتطبيق العملي
- استمر في ممارسة كتابة الأكواد يوميا
- نلتقي في الدرس القادم من دورة HTML
