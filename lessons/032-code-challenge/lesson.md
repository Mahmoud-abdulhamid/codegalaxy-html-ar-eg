# HTML Hyperlinks Challenge

المصدر: https://www.w3schools.com/html/html_challenges_links.asp

## مقدمة في الروابط التشعبية

مرحبا بكم في درس الروابط التشعبية Hyperlinks في لغة HTML.

- الروابط هي أساس تصفح الويب
- نستخدم a Element لإنشاء الروابط
- الروابط تربط بين الصفحات والمواقع

## قواعد كتابة الروابط

نستخدم a Element مع Attribute المسمى href لتحديد وجهة الرابط.

```html
<a href="url">
  هذا هو نص الرابط
</a>
```

## تطبيق عملي للروابط

مثال عملي لكيفية كتابة رابط لموقع خارجي.

```html
<a href="https://www.w3schools.com">
  زيارة موقع W3Schools
</a>
```

## خصائص إضافية للروابط

استخدام target="_blank" لفتح الرابط في صفحة جديدة.

```html
<a href="https://google.com" 
   target="_blank">
  فتح في صفحة جديدة
</a>
```

## أفضل الممارسات

نصائح لتحسين تجربة المستخدم في الروابط.

- استخدم نصوصا وصفية للروابط
- تأكد من صحة الروابط في href
- استخدم target عند الحاجة فقط
- اختبر الروابط في Web Browser

## خلاصة الدرس

خلاصة: الروابط هي جوهر الويب، استمروا في التدريب.

- تعلمنا استخدام a Element
- فهمنا أهمية href Attribute
- تعرفنا على target Attribute
- أهمية النصوص الوصفية للروابط
