# تعلم كيفية بناء Nested Table في HTML

المصدر: https://www.w3schools.com/howto/howto_html_table_nested.asp

## مقدمة حول الجداول المتداخلة

مرحبا بكم في درس اليوم حول كيفية إنشاء Nested Table داخل صفحات الويب باستخدام HTML.

- الجداول المتداخلة هي جداول توضع داخل خلايا جدول آخر
- تستخدم لتنظيم البيانات المعقدة
- تعتمد على العناصر الأساسية table و tr و td

## القواعد الأساسية للـ Nested Table

يتم إنشاء الجدول المتداخل عبر وضع عنصر table بالكامل داخل عنصر td الخاص بالجدول الرئيسي.

- الجدول الخارجي هو الحاوية الأساسية
- الجدول الداخلي يوضع داخل عنصر td
- يجب إغلاق جميع الـ Tags بشكل صحيح

## كتابة الكود البرمجي للجدول الخارجي

نبدأ بإنشاء الجدول الخارجي ثم نجهز الخلية td لاستقبال الجدول الداخلي.

```html
<table>
  <tr>
    <td>Cell
      <table>
```

## إضافة صفوف وخلايا الجدول الداخلي

نضيف صفوف الجدول الداخلي ونغلق جميع العناصر البرمجية بدقة.

```html
        <tr><td>Cell 1</td></tr>
        <tr><td>Cell 2</td></tr>
        <tr><td>Cell 3</td></tr>
        <tr><td>Cell 4</td></tr>
      </table>
    </td>
  </tr>
</table>
```

## ملاحظات هندسية وأفضل الممارسات

استخدم المسافات البادئة Indentation لتنظيم الكود وتسهيل قراءته وصيانته.

- حافظ على ترتيب الـ Tags
- استخدم Indentation لتوضيح التداخل
- تأكد من إغلاق كل عنصر بشكل صحيح
