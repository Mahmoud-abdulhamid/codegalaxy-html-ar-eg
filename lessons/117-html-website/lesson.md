# HTML Website Hosting and Spaces

المصدر: https://www.w3schools.com/html/html_website.asp

## مقدمة استضافة مواقع الويب

مرحبا بكم في درس استضافة مواقع الويب وبناء المشاريع باستخدام HTML وتطوير مهارات البرمجة.

- استضافة مواقع الويب بطريقة آمنة وسريعة
- تطوير مهارات البرمجة عبر مشاريع عملية
- الاستعانة بالمساعد الذكي AI Tutor

## اختيار خطط الاستضافة والاشتراكات

الاشتراك في خطط الاستضافة يدعم نشر التعليم للجميع مع إمكانية شراء Domain خاص أو ربطه.

- دعم رسالة التعليم المتاح للجميع
- شراء Domain جديد بكل سهولة
- ربط Domain موجود مسبقا بموقعك

## توفير الوقت باستخدام Templates والمساعد الذكي

تساعدك بيئة Spaces والمساعد الذكي kAI على فحص الأكواد واكتشاف الأخطاء بسرعة فائقة.

- استخدام Templates الجاهزة لتوفير الوقت
- الاستعانة بالمساعد الذكي kAI Tutor
- فحص الأكواد البرمجية وتحسين هيكلتها

## أدوات التطوير السحابية السهلة

توفر البيئات السحابية أدوات مثل Terminal و Database و File Navigator لإدارة المشاريع بكفاءة.

- بيئة عمل سحابية متكاملة Cloud-based
- استخدام Terminal و Log المتقدمة
- إدارة الملفات وقواعد البيانات بسهولة

## الفرق بين Basic Spaces و Fullstack Spaces

تتيح خطط Basic Spaces بناء واجهات Frontend بينما تدعم Fullstack Spaces تطوير الواجهات الخلفية أيضا.

- Basic Spaces مخصصة لتطوير واجهات Frontend
- دعم لغات HTML و CSS و JavaScript الأساسية
- Fullstack Spaces تدعم Frontend و Backend معا

## التقنيات المدعومة في Fullstack Spaces

تتضمن خطط Fullstack تقنيات متقدمة مثل PHP و Python و React.js و Node.js لبناء تطبيقات متكاملة.

- دعم لغات برمجة Servers مثل PHP و Python
- مكتبات وإطارات عمل مثل React.js و Vue.js
- استخدام Node.js و Django للتطبيقات الشاملة

## إدارة الاشتراكات والتجديد التلقائي

يتم تجديد الاشتراك شهريا مع إمكانية التحكم في التجديد التلقائي والاحتفاظ بكافة المزايا المدفوعة.

- التجديد التلقائي الشهري للاشتراكات
- استمرار الوصول للمزايا طوال فترة الاشتراك
- إمكانية التواصل مع الدعم الفني للمجموعات

## خلاصة الدرس والدعم الفني

في ختام الدرس، يمكنكم التواصل مع فريق الدعم الفني للاستفسارات المؤسسية وبناء مشاريعكم بنجاح.

- التواصل مع الدعم الفني للحسابات المتعددة
- تطبيق المفاهيم عبر منصة CodeGalaxy
- مواصلة التعلم وبناء مشاريع الويب المختلفة
