# عناصر الأكواد والحوسبة في لغة HTML

المصدر: https://www.w3schools.com/html/html_computercode_elements.asp

## مقدمة حول عناصر الأكواد في لغة HTML

تعرف على عناصر HTML المخصصة لتعريف الأكواد ومدخلات المستخدم.

- تتضمن لغة HTML عناصر خاصة لتمثيل الأكواد
- عرض مدخلات المستخدم البرمجية
- تحسين تنسيق النصوص التقنية

## استخدام kbd لمدخلات لوحة المفاتيح

استخدام kbd لتعريف الإدخال عبر لوحة المفاتيح بخط monospace.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>Save the document
      by pressing
      <kbd>Ctrl + S</kbd></p>
      </body>
    </html>
```

## استخدام samp لمخرجات البرامج

استخدام samp لعرض مخرجات البرامج والنماذج التقنية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>Message:</p>
    <p><samp>File not found.
      Press F1</samp></p>
  </body>
</html>
```

## استخدام code لكتابة الشفرات

استخدام code لعرض الأكواد البرمجية بخط monospace الافتراضي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <code>
      x = 5;
      y = 6;
      z = x + y;
    </code>
  </body>
</html>
```

## الحفاظ على المسافات باستخدام pre مع code

دمج code داخل pre للحفاظ على المسافات والفراغات النصية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <pre>
      <code>
        x = 5;
        y = 6;
        z = x + y;
      </code>
    </pre>
  </body>
</html>
```

## استخدام var لتعريف المتغيرات

استخدام var لتعريف المتغيرات البرمجية أو الرياضية بخط مائل.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>Area is:
      1/2 x <var>b</var>
    x <var>h</var></p>
</body>
</html>
```

## خلاصة عناصر الحوسبة في لغة HTML

ملخص شامل لاستخدام عناصر الأكواد والمتغيرات في HTML.

- kbd لمدخلات لوحة المفاتيح
- samp لمخرجات البرامج
- code و pre لعرض الأكواد مع المسافات
- var للمتغيرات الرياضية والبرمجية
