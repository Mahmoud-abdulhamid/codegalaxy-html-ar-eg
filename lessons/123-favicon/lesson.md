# كيفية إضافة Favicon في صفحات HTML

المصدر: https://www.w3schools.com/howto/howto_html_favicon.asp

## مقدمة الدرس

تعرف على كيفية إضافة Favicon إلى صفحة الويب لزيادة احترافية موقعك.

- تعلم كيفية إضافة Favicon في لغة HTML
- تحسين المظهر البصري لعلامة التبويب في المتصفح
- جعل موقع الويب يبدو أكثر احترافية وتميزا

## ما هو Favicon

Favicon هو صورة صغيرة تظهر بجانب عنوان الصفحة في علامة تبويب المتصفح.

- صورة مصغرة تظهر بجانب عنوان الصفحة
- تظهر في تبويب المتصفح لتسهيل التعرف على الموقع
- يمكنك استخدام أي صورة تفضلها كأيقونة للموقع

## مواصفات وتصميم Favicon

يجب أن تكون الأيقونة بسيطة وذات تتباين عالي لتظهر بوضوح.

- يجب أن تكون الصورة بسيطة نظرا لصغر حجمها
- يفضل استخدام تباين عالي لضمان وضوح التفاصيل
- يمكن تصميم الأيقونات عبر مواقع مثل favicon.cc

## تخزين ملف Favicon

احفظ الأيقونة في المجلد الرئيسي للسيرفر أو داخل مجلد images.

- حفظ الملف في الجذر الرئيسي للويب سيرفر
- أو إنشاء مجلد مخصص باسم images للأيقونات
- الاسم الأكثر شيوعا للملف هو favicon.ico

## كود الصفحة الجزء الأول

نبدأ كتابة مستند HTML مع تحديد DOCTYPE وعنصر head.

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Page Title</title>
```

## كود الصفحة الجزء الثاني

نضيف عنصر link داخل head لتحديد مسار ملف الأيقونة.

```html
  <link rel="icon" 
        type="image/x-icon" 
        href="/images/favicon.ico">
</head>
```

## كود الصفحة الجزء الثالث

نكمل هيكل الصفحة بإضافة body وعناصر المحتوى النصي والمرئي.

```html
<body>
  <h1>This is a Heading</h1>
  <p>This is a paragraph.</p>
</body>
</html>
```

## معاينة النتيجة في المتصفح

قم بحفظ الملف وتحديث المتصفح لمشاهدة ظهور الأيقونة بجانب العنوان.

- احفظ ملف index.html في سيرفرك المحلي
- قم بإعادة تحميل الصفحة في متصفح الويب
- شاهد ظهور أيقونة Favicon بجانب عنوان الصفحة

## خلاصة الدرس

خلاصة الدرس: تعلم ربط Favicon عبر عنصر link وتجربة التطبيق العملي.

- Favicon يمنح مواقع الويب طابعا احترافيا
- استخدام Tag link مع rel يساوي icon
- تابعوا الدورات التطبيقية لاحتراف لغة HTML
