# HTML Tables

المصدر: https://www.w3schools.com/html/html_tables.asp

## مقدمة الجداول في لغة HTML

تستستخدم لغة HTML لإنشاء جداول منظمة في صفوف وأعمدة.

- تستخدم لغة HTML لبناء الجداول
- تنظيم البيانات في صفوف وأعمدة
- استخدام عناصر متخصصة لهيكلة الجدول

## هيكل الجدول الأساسي

يتكون الجدول من خلايا داخل صفوف وأعمدة باستخدام الحاوية الرئيسية.

- الحاوية الرئيسية تبدأ وتنتهي بـ table
- تحتوي على صفوف وخلايا بيانات
- أساس تنظيم البيانات بصريا في المتصفح

## كتابة جدول بيانات بسيط

مثال عملي لبناء جدول بيانات متكامل باستخدام العناصر الأساسية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <table>
      <tr>
        <th>Company</th>
        <th>Contact</th>
      </tr>
      <tr>
        <td>Emil</td>
        <td>Tobias</td>
      </tr>
    </table>
  </body>
</html>
```

## شرح تفصيلي لعناصر الخلايا والصفوف

عنصر td يمثل بيانات الخلية بينما يمثل tr صف الجدول.

- عنصر td مخصص لبيانات الجدول
- عنصر tr مخصص لصفوف الجدول
- تطابق عدد الخلايا في كل صف ضروري

## استخدام عناصر العناوين Table Headers

نستخدم عنصر th لتعريف خلايا العناوين بخط عريض ومتمركز.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <tr>
      <th>Person 1</th>
      <th>Person 2</th>
      <th>Person 3</th>
    </tr>
  </body>
</html>
```

## معاينة الجدول في المتصفح

عرض شكل الجدول المرئي داخل متصفح الويب.

## أفضل الممارسات البرمجية للجداول

أفضل الممارسات لضمان سلامة هيكل الجدول وتوافق البيانات.

- تساوي عدد الخلايا في الصفوف
- إمكانية تضمين عناصر HTML داخل الخلايا
- استخدام CSS لتنسيق المظهر النهائي

## خلاصة الدرس ودعوة للتجربة

خلاصة شاملة لإنشاء الجداول والتعامل مع عناصرها بكفاءة.

- تم تعلم عناصر table و tr و td و th
- تجربة الأكواد العملية لترسيخ الفهم
- الاستعداد للدرس القادم حول تنسيق الجداول
