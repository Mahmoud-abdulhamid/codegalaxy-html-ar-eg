# HTML Tables Structure and Elements

المصدر: https://www.w3schools.com/html/html_tables.asp

## مقدمة الجداول في HTML

تتيح لنا لغة HTML تنظيم البيانات في صفوف وأعمدة باستخدام الجدول الأساسي.

- تنظيم البيانات في صفوف وأعمدة
- استخدام عنصر table الأساسي
- بناء هيكل واضح للمعلومات

## تعريف الجدول والصفوف

يبدأ كل صف بـ tr ويحتوي على خلايا بيانات داخل عناصر td.

```html
<table>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
</table>
```

## إضافة عدة صفوف للجدول

يمكنك إضافة عدة صفوف مع الحرص على تساوي عدد الخلايا في كل صف.

```html
<table>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
  <tr>
    <td>16</td>
    <td>14</td>
    <td>10</td>
  </tr>
</table>
```

## ترويسة الجدول باستخدام th

نستخدم عنصر th بدلا من td لتحديد خلايا الترويسة والعناوين.

```html
<tr>
  <th>Company</th>
  <th>Contact</th>
  <th>Country</th>
</tr>
```

## معاينة الجدول الكامل

صورة توضح جدول HTML متكامل يضم عناوين وبيانات منظمة.

## خصائص عناصر الترويسة th

النص داخل عناصر th يكون غليظا ووسط المحاذاة افتراضيا ويمكن تعديله بـ CSS.

- الخط يكون غليظا بشكل افتراضي
- المحاذاة تكون في المنتصف تلقائيا
- إمكانية تخصيص المظهر بالكامل عبر CSS

## محتويات خلايا الجدول المتنوعة

يمكن أن تحتوي خلايا الجدول على نصوص، صور، قوائم، روابط، أو جداول أخرى.

- النصوص والصور والروابط
- القوائم والجداول المتداخلة
- مرونة عالية في تصميم المحتوى

## خلاصة الدرس ودعوة للتجربة

خلاصة هيكل الجداول في HTML ودعوة للتطبيق العملي المستمر.

- مراجعة شاملة ل Tags الجداول
- التطبيق العملي للأكواد البرمجية
- تابعونا للمزيد من الدروس المتقدمة
