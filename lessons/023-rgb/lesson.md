# تعلم ألوان RGB و RGBA في HTML

المصدر: https://www.w3schools.com/html/html_colors_rgb.asp

## مقدمة ألوان RGB و RGBA

مرحبا بكم في دورة HTML. سنتعرف اليوم على كيفية تحديد الألوان باستخدام نظامي RGB و RGBA.

- تحديد الألوان بدقة في صفحات الويب
- استخدام نظام RGB لخلط الألوان الأساسية
- إضافة الشفافية عبر قناة Alpha في RGBA

## مفهوم نظام RGB

يمثل نظام RGB مصادر الضوء الثلاثة: الأحمر، الأخضر، والأزرق بقيم بين 0 و255.

- قيم المعاملات تتراوح بين 0 و255
- إجمالي عدد الألوان المحتملة ضخم جدا
- الصيغة العامة هي rgb(red, green, blue)

## أمثلة الألوان الأساسية

لعرض اللون الأحمر نضع القيمة 255 للأحمر وباقي المعاملات صفر.

```html
rgb(255, 0, 0);
rgb(0, 255, 0);
rgb(0, 0, 255);
```

## عرض الأسود والأبيض

لعرض اللون الأسود نضع كافة القيم صفرا، وللأبيض نضعها 255.

```html
rgb(0, 0, 0);
rgb(255, 255, 255);
```

## تدريجات الرمادي

تحدد درجات الرمادي باستخدام قيم متساوية للمتغيرات الثلاثة.

```html
rgb(60, 60, 60);
rgb(120, 120, 120);
rgb(200, 200, 200);
```

## مفهوم نظام RGBA

نظام RGBA هو امتداد لـ RGB مضافا إليه قناة الشفافية Alpha.

- القيم من 0.0 تعني شفاف تماما
- القيمة 1.0 تعني غير شفاف على الإطلاق
- الصيغة rgba(red, green, blue, alpha)

## أمثلة عملية على RGBA

نكتب كود RGBA بتحديد الألوان الثلاثة مع إضافة قيمة الشفافية.

```html
rgba(255, 0, 0, 0.3);
rgba(0, 255, 0, 0.6);
rgba(0, 0, 255, 1.0);
```

## خلاصة الدرس

تعرفنا على ألوان RGB و RGBA. ننصحكم بتجربة الأكواد بأنفسكم عبر الابط في الوصف.

- إتقان تمثيل الألوان الضوئية في HTML
- التحكم في الشفافية باستخدام Alpha
- تطوير مهارات التصميم وتجربة الأكواد
