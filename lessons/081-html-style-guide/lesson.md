# قواعد كتابة كود HTML احترافي

المصدر: https://www.w3schools.com/html/html5_syntax.asp

## مقدمة في معايير HTML

كتابة كود HTML نظيف ومنظم تجعل العمل أكثر احترافية وسهولة في الفهم.

- كتابة كود HTML نظيف
- تسهيل قراءة الكود للآخرين
- اتباع أفضل الممارسات البرمجية

## أهمية DOCTYPE

يجب دائما تعريف DOCTYPE في السطر الأول من مستند HTML.

```html
<!DOCTYPE html>
```

## قواعد كتابة Tags

استخدم الحروف الصغيرة لأسماء العناصر وأغلق جميع Tags.

```html
<section>
  <p>هذه فقرة نصية.</p>
</section>
```

## معايير Attributes

يجب وضع قيم Attributes بين علامتي تنصيص دائما.

```html
<table class="striped">
  <tr>
    <td>بيانات</td>
  </tr>
</table>
```

## التعامل مع الصور

حدد دائما alt و width و height للصور.

```html
<img src="logo.png" 
     alt="شعار الموقع" 
     width="128" 
     height="128">
```

## الهيكل الأساسي للصفحة

الهيكل الكامل يتضمن head و body مع تحديد اللغة.

```html
<!DOCTYPE html>
<html lang="ar">
<head>
  <title>عنوان الصفحة</title>
</head>
<body>
  <h1>مرحباً بكم</h1>
</body>
</html>
```

## خلاصة الدرس

التزم بالقواعد البرمجية لضمان جودة واحترافية الكود.

- استخدم الحروف الصغيرة دائما
- أغلق جميع العناصر و Tags
- استخدم Viewport للأجهزة المحمولة
- نظم الكود بمسافات بادئة
