# HTML Uniform Resource Locators and URL Encoding

المصدر: https://www.w3schools.com/html/html_urlencode.asp

## مقدمة حول URL

مرحبا بكم في درس جديد حول URL وعناوين الويب.

- URL هو مصطلح آخر لعنوان الويب
- يتكون من كلمات أو عنوان IP رقمي
- تستخدمه متصفحات الويب لطلب الصفحات

## هيكل بناء URL

نتعرف على القواعد الأساسية لبناء عنوان URL.

```text
scheme://prefix.domain:port/path/filename
```

## مفهوم URL Encoding

توضيح أهمية URL Encoding لتحويل الرموز خارج نطاق ASCII.

- URLs ترسل عبر الإنترنت باستخدام ASCII فقط
- تتحول الرموز الخارجية إلى تنسيق خاص
- يتم استبدال الرموز بعلامة النسبة المئوية وأرقام ست عشرية

## معالجة المسافات والرموز الخاصة

كيفية معالجة المسافات والرموز الخاصة في عناوين الويب.

- URLs لا يمكن أن تحتوي على مسافات فارغة
- تستبدل المسافة بعلامة زائد (+) أو 20
- يضمن ذلك سلامة نقل البيانات عبر المتصفح

## التفاعل مع نموذج الإدخال و Submit

دور متصفح الويب في تشفير المدخلات عند النقر على Submit.

- الضغط على Submit يشفر المدخلات تلقائيا
- يقوم الـ Web Server بعرض المدخلات المستلمة
- ضمان صحة البيانات المنقولة ووضوحها

## ترميز النصوص في HTML5

مجموعة الرموز الافتراضية UTF-8 في HTML5.

- المتصفح يشفر المدخلات حسب الـ character-set المستخدم
- الترميز الافتراضي في HTML5 هو UTF-8
- دعم كامل لجميع اللغات والرموز العالمية

## خلاصة الدرس

خلاصة شاملة لمفاهيم URL Encoding وتشفير روابط الويب.

- فهم تركيب عناوين URL وأهميتها
- إتقان استخدام URL Encoding للرموز الخاصة
- معرفة دور UTF-8 في متصفحات الويب الحديثة
