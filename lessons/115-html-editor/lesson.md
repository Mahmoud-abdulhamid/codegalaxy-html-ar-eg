# HTML Editor and Code Structure

المصدر: https://www.w3schools.com/html/html_editor.asp

## مقدمة حول الـ HTML Editor

مرحبا بكم في درس جديد حول HTML Editor وكيفية كتابة وتعديل أكواد الويب وعرض النتائج في المتصفح.

- استخدام الـ HTML Editor لكتابة وتعديل الأكواد
- التعامل مع لغات الويب الأساسية HTML و CSS و JavaScript
- معاينة النتائج بشكل فوري وسريع داخل الـ Web Browser

## القواعد الأساسية لمستند HTML

يبدأ مستند HTML بتعريف DOCTYPE HTML لتحديد إصدار اللغة وعرض الصفحة بشكل صحيح.

- أهمية تعريف DOCTYPE HTML في بداية المستند
- مساعدة الـ Web Browser في فهم الإصدار
- ضمان عرض محتوى الصفحة بدقة واحترافية

## الهيكل البرمجي للـ Root Element

نلاحظ في المثال البرمجي وجود Root Element ممثلا في عنصر html الذي يحتوي جميع عناصر الصفحة.

```html
<!DOCTYPE html>
<html>
<title>HTML Tutorial</title>
```

## قسما الـ head والـ body

يحتوي المستند على قسم head لتحديد title ثم قسم body الذي يضم المحتوى المرئي.

```html
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>
```

## معاينة النتيجة في المتصفح

بعد كتابة الأكواد، يتيح زر Try it Yourself معاينة عناصر h1 و p داخل المتصفح.

## بناء ونشر مواقع الويب

تتيح أدوات مثل W3Schools Spaces حفظ وتشغيل وإدارة ونشر الأكواد عبر الإنترنت.

- حفظ الأكواد البرمجية وإنشاء مواقع الويب الخاصة
- استخدام منصة W3Schools Spaces لكتابة ونشر الكود
- إدارة وتشغيل مشاريع الويب أونلاين بكل سهولة

## خلاصة الدرس والدعوة للتجربة

في ختام الدرس، نؤكد على أهمية التدرب المستمر وتجربة الأكواد من خلال الروابط المتاحة.

- أهمية التدريب المستمر على كتابة Tags
- استكشاف المزيد من الأمثلة والتمارين العملية
- متابعة دورة لغة HTML من البداية حتى الاحتراف
