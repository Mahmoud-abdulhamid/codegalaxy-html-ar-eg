# HTML Plug-ins and Embedded Objects

المصدر: https://www.w3schools.com/html/html_object.asp

## مقدمة حول Plug-ins

تعد Plug-ins برامج حاسوبية مصممة لتوسيع الوظائف القياسية لمتصفح الويب.

- توسيع وظائف متصفح الويب
- استخدامات متعددة مثل تشغيل Java applets
- عرض ملفات الوسائط المتعددة
- تحذير: معظم المتصفحات الحديثة لم تعد تدعم هذه التقنيات

## عنصر object

يستخدم عنصر object لتعريف كائن مضمن داخل مستند HTML وهو مدعوم من جميع المتصفحات.

- يدعم تضمين Plug-ins مثل PDF readers
- يمكن استخدامه لتضمين ملفات HTML
- يعد عنصرا مرنا في هيكلة صفحات الويب

## مثال على عنصر object

مثال يوضح كيفية تضمين ملف HTML داخل صفحة باستخدام عنصر object.

```html
<object 
  width="100%" 
  height="500px" 
  data="snippet.html">
</object>
```

## عنصر embed

عنصر embed هو وسيلة أخرى لتضمين الكائنات في صفحات الويب وأصبح جزءا من معايير HTML5.

- مدعوم في جميع المتصفحات الرئيسية
- يستخدم لتضمين الكائنات في مستند HTML
- لم يكن جزءا من مواصفات HTML قبل HTML5

## مثال على عنصر embed

مثال يوضح استخدام عنصر embed لتضمين صورة، مع ملاحظة أنه لا يحتوي على Closing Tag.

```html
<embed src="audi.jpeg">
```

## ملاحظات هامة

يجب الحذر من استخدام التقنيات القديمة والبحث دائما عن البدائل الحديثة لضمان توافقية الموقع.

- تجنب Java Applets و ActiveX
- استخدم البدائل الحديثة لـ Flash
- اختبر دائما توافقية الكود في المتصفحات الحديثة
