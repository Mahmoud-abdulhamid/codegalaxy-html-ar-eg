# HTML File Paths Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_filepaths.asp

## مقدمة تحدي مسارات الملفات

مرحبا بكم في هذا التحدي العملي من دورة لغة HTML، سنتدرب اليوم على حل مشكلات مسارات الملفات File Paths واكتشاف الأخطاء وإصلاحها بدقة.

- اختبار فهم مسارات الملفات File Paths
- اكتشاف الأخطاء الشائعة في الروابط
- إصلاح مسارات الصور والمستندات
- تعزيز مهارات التطوير العملي للويب

## مفهوم File Paths الأساسي

تعتبر مسارات الملفات أو File Paths العنصر الأساسي لربط الصور والصفرات ببعضها، وعند كتابة رابط خاطئ فلن يظهر المحتوى.

- أهمية File Paths في ربط الموارد
- الفرق بين المسارات المطلقة والنسبية
- تجنب الروابط المعطلة Broken Links
- التأكد من صحة امتدادات الملفات

## كود اختبار المسارات

لاحظ معي في هذا المثال كيف نواجه تحديا فعليا لإصلاح مسار صورة مفقودة داخل عنصر image مع التأكد من المجلدات.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="challenge">
      <p>Fix the image path:</p>
      <img src="images/pic.jpg" alt="Picture">
    </div>
  </body>
</html>
```

## تحليل أجزاء المسار

عند كتابة Paths في عناصر HTML يجب الانتباه لاسم المجلد وامتداد الملف مثل jpg، وأي خطأ إملائي سيؤدي لفشل التحميل.

- التحقق من حالة الأحرف Case Sensitivity
- كتابة المجلد الصحيح في attribute الـ src
- استخدام الشرطة المائلة / للفصل بانتظام
- مراجعة امتدادات الملفات بدقة عالية

## المسارات النسبية للملفات

نستخدم النقطتين والشرطة المائلة للصعود مجلدا واحدا للأعلى في شجرة المجلدات لاجتياز تحديات الويب وبناء مواقع منظمة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <a href="../index.html">Go Back Home</a>
  </body>
</html>
```

## أفضل الممارسات وحل التحديات

لتجنب مشكلات الروابط المكسورة احرص دائما على استخدام المسارات النسبية للملفات الداخلية والمطلقة للمواقع الخارجية.

- تفضيل المسارات النسبية للمشروع المحلي
- استخدام المسارات المطلقة للمواقع الخارجية
- التحقق المستمر من عمل الروابط
- تنظيم المجلدات لتجنب الأخطاء المعقدة

## خلاصة التحدي البرمجي

بهذا نكون قد انتهينا من تحليل تحدي مسارات الويب بنجاح. أدعوكم لتجربة حل التحدي بأنفسكم عبر الرابط في الوصف.

- استكمال تحدي File Paths بنجاح
- تطبيق الأكواد بشكل عملي ومباشر
- زيارة رابط المصدر لمزيد من التدريب
- انتظاركم في الدرس القادم من الكورس
