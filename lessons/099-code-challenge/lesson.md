# HTML Canvas Element Fundamentals

المصدر: https://www.w3schools.com/html/html_challenges_canvas.asp

## مقدمة حول canvas

مرحبا بكم في درس جديد من دورة HTML. سنتعرف اليوم على عنصر canvas القوي والمهم في HTML5، والذي يستخدم لرسم الرسومات والجرافيكس مباشرة داخل صفحة الويب.

- عنصر canvas هو جزء من HTML5
- يستخدم لرسم الرسومات برمجيا
- يعتمد على JavaScript للتحكم بالرسم
- أداة أساسية لتطوير الألعاب والرسوم البيانية

## هيكلية عنصر canvas

لإضافة canvas إلى صفحة الويب، نستخدم Element باسم canvas. هذا العنصر يعمل كلوحة رسم فارغة، ونحتاج لتحديد أبعاده باستخدام Attributes مثل width و height.

```html
<canvas id="myCanvas" 
        width="200" 
        height="100">
</canvas>
```

## تحليل Attributes البرمجية

استخدام id ضروري للوصول للعنصر عبر JavaScript. بينما تحدد width و height مساحة الرسم بالبكسل. بدون هذه Attributes، سيكون العنصر بحجم افتراضي قد لا يناسب تصميمك.

- id: معرف فريد للعنصر
- width: عرض لوحة الرسم
- height: ارتفاع لوحة الرسم
- يجب إغلاق العنصر بـ Closing Tag

## تحدي البرمجة

حان وقت التحدي! قم بإنشاء canvas بعرض 300 وارتفاع 200. تذكر أن كتابة الكود بشكل صحيح هي الخطوة الأولى لإتقان هذه التقنية الرائعة في صفحات الويب.

```html
<canvas id="testCanvas" 
        width="300" 
        height="200">
</canvas>
```

## أفضل الممارسات

من أفضل الممارسات وضع نص بين Start Tag و End Tag لعنصر canvas، ليظهر للمستخدمين الذين تستخدم متصفحاتهم إصدارات قديمة لا تدعم هذه التقنية.

```html
<canvas id="myCanvas" width="200" height="100">
  متصفحك لا يدعم canvas.
</canvas>
```

## خاتمة الدرس

بهذا نكون قد أتممنا درس اليوم حول canvas. أدعوكم لتجربة الكود بأنفسكم عبر الرابط الموجود في وصف الفيديو. لا تترددوا في طرح أسئلتكم، وإلى اللقاء في درس قادم.

- راجعنا أساسيات canvas
- تعلمنا كيفية تحديد الأبعاد
- ناقشنا أهمية الـ fallback text
- استعد للدرس القادم حول SVG
