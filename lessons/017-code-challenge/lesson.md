# HTML Formatting Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_formatting.asp

## مقدمة تحدي تنسيق النصوص

مرحبا بكم في درس جديد لاختبار مهارات تنسيق النصوص في لغة HTML وحل التحديات البرمجية.

- مرحبا بكم في درس تحدي تنسيق النصوص
- اختبار الفهم العملي لعناصر تنسيق HTML
- تطبيق المهارات المكتسبة في مشاريع حقيقية

## مفاهيم تنسيق النصوص الأساسية

تعتمد لغة HTML على عناصر مخصصة لتنسيق النصوص وتثبيت المفاهيم عبر التحديات العملية.

- أهمية عناصر تنسيق النصوص في صفحات الويب
- كيفية اختبار المعرفة عبر التحديات البرمجية
- التعامل مع النصوص بصورة جذابة وواضحة

## كتابة هيكل التحدي البرمجي

نبدأ كتابة هيكل التحدي في لغة HTML وإضافة النصوص داخل قسم <body>.

```html
<!DOCTYPE html>
<html>
<body>
<p>Test your skills!</p>
</body>
</html>
```

## تطبيق تاجوز التنسيق داخل الكود

نضيف تنسيقات النصوص المختلفة ونرتب Tags بشكل صحيح داخل كود HTML.

```html
<p>This is <b>bold</b> text.</p>
<p>This is <i>italic</i> text.</p>
```

## استعراض مخرجات التحدي في المتصفح

تظهر مخرجات التحدي بوضوح داخل المتصفح مع تطبيق كافة التنسيق بدقة.

- معاينة النتيجة عبر Web Browser
- التحقق من صحة ظهور النصوص المنسقة
- التأكد من خلو الأكواد من الأخطاء البرمجية

## أفضل الممارسات في كتابة عناصر HTML

الالتزام بأفضل الممارسات مثل إغلاق Tags يضمن قراءة سليمة للملفات.

- إغلاق العناصر البرمجية بصورة صحيحة
- تنظيم الأكواد لتسهيل قراءتها وصيانتها
- تجنب الأخطاء الشائعة في كتابة Tags

## خلاصة الدرس ودعوة للتجربة العملية

خلاصة الدرس تدعوكم لتجربة التحديات البرمجية وتطوير مهاراتكم باستمرار.

- أهمية تطبيق التحديات البرمجية بانتظام
- مراجعة الأمثلة وفهم القواعد جيدا
- انتظرونا في الدرس القادم لمزيد من المعرفة
