# HTML Semantic Elements

المصدر: https://www.w3schools.com/html/html5_semantic_elements.asp

## مقدمة عن العناصر الدلالية

مرحبا بكم في درس العناصر الدلالية Semantic Elements في لغة HTML.

- العناصر الدلالية تعبر عن محتواها بوضوح
- تساعد متصفحات الويب وفريق التطوير
- تجعل هيكل صفحة الويب مفهوما ومنظما

## الفرق بين العناصر الدلالية وغير الدلالية

الفرق بين العناصر غير الدلالية والعناصر الدلالية الواضحة.

- العناصر div و span لا تعبر عن محتواها
- العناصر img و table و article دلالية وواضحة
- تحسين بنية الكود وسهولة قراءته

## استخدام عنصر section

عنصر section يحدد قسما موضوعيا مستقلا داخل مستند الويب.

```html
<section>
  <h1>WWF</h1>
  <p>The World Wide Fund for Nature.</p>
</section>
```

## استخدام عنصر article

عنصر article يحدد محتوى مستقلا بذاته وقابلا للنشر المنفصل.

```html
<article>
  <h2>Google Chrome</h2>
  <p>Google Chrome is a web browser.</p>
</article>
```

## عناصر header و footer

عنصرا header و footer لتنظيم رأس وتذييل صفحات ومقالات الويب.

```html
<header>
  <h1>Website Title</h1>
</header>
<footer>
  <p>Author: John Doe</p>
</footer>
```

## عناصر nav و aside

عنصرا nav و aside لتحديد روابط التنقل والمحتوى الجانبي.

```html
<nav>
  <a href="/">Home</a> |
  <a href="/about">About</a>
</nav>
<aside>
  <h4>Sidebar</h4>
</aside>
```

## عناصر figure و figcaption

عنصرا figure و figcaption لعرض الصور مع تعليقاتها التوضيحية.

```html
<figure>
  <img src="pic.jpg" alt="Trulli">
  <figcaption>Fig1. - Trulli, Italy.</figcaption>
</figure>
```

## خلاصة العناصر الدلالية

خلاصة استخدام العناصر الدلالية في تحسين SEO وإمكانية الوصول.

- تحسين محركات البحث SEO بشكل ملحوظ
- دعم أدوات القراءة لذوي الاحتياجات الخاصة
- تنظيم وتسهيل صيانة أكواد صفحات الويب
