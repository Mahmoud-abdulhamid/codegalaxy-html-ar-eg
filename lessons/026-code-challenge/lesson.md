# HTML Colors Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_colors.asp

## مقدمة تحدي الألوان

مرحبا بكم في درس تحدي الألوان الجديد من دورة HTML وتطبيق المهارات بشكل عملي.

- تطوير مهارات تصميم صفحات الويب
- اختبار الفهم العملي لألوان HTML
- حل تحدي Color Names البرمجي

## فكرة تحدي الألوان

تعتمد فكرة التحدي على اختبار فهم استخدام الألوان وأسماها في عناصر HTML المختلفة.

- استخدام أسماء الألوان Color Names
- تنسيق الخلفيات والنصوص البرمجية
- تقييم المعرفة البرمجية عبر التحدي

## هيكل كود التحدي

نظرة على هيكل كود التحدي البرمجي وبدء المستند بأسلوب منظم وسليم.

```html
<!DOCTYPE html>
<html>
<body>
  <h1 style="color:red;">
    Color Challenge
  </h1>
</body>
</html>
```

## شرح أجزاء الكود

تلوين العنصر h1 باستخدام خاصية style وقيمة red لتطبيق التنسيق المباشر.

```html
<h1 style="color:red;">
  Color Challenge
</h1>
```

## معاينة المخرجات في المتصفح

معاينة النتيجة في المتصفح وظهور النص باللون الأحمر لتأكيد نجاح الكود.

- عرض النتيجة في Web Browser
- ظهور النص باللون الأحمر الصحيح
- اجتياز خطوة التحدي بنجاح

## خيارات الألوان الإضافية

تتيح لك التحديات تجربة خيارات إضافية مثل Blue و Green واكتشاف قدرات لغة HTML.

- تجربة أسماء ألوان متعددة
- استخدام قيم Hex و RGB
- اكتشاف قدرات تنسيق العناصر

## أفضل الممارسات البرمجية

من أفضل الممارسات البرمجية كتابة عناصر نظيفة وإغلاق Tags بشكل صحيح.

- كتابة أكواد نظيفة ومقروءة
- التأكد من إغلاق Tags تماما
- تفادي الأخطاء التقنية في المتصفح

## خلاصة الدرس والدعوة للتجربة

خلاصة الدرس ودعوة لتجربة الأكواد بأنفسكم ومراجعة الابط في الوصف مع المدرب محمود عبدالحميد.

- تطبيق التمارين بشكل عملي
- مراجعة الرابط المرفق في الوصف
- متابعة دورة HTML مع محمود عبدالحميد
