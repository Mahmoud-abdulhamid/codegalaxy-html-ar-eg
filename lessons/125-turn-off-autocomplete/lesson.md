# إيقاف خاصية الإكمال التلقائي في لغة HTML

المصدر: https://www.w3schools.com/howto/howto_html_autocomplete_off.asp

## مقدمة الدرس

مرحبا بكم في درس جديد من دورة HTML لتعلم تعطيل خاصية autocomplete في حقول الإدخال.

- أهلا بكم في دورة HTML
- موضوع الدرس هو إيقاف autocomplete
- تحسين الأمان وتجربة المستخدم في الويب

## مفهوم خاصية Autocomplete

تخزن متصفحات الويب البيانات لتقديم اقتراحات سريعة، لكننا قد نحتاج لتعطيلها لأسباب أمنية.

- المتصفحات تخزن البيانات المدخلة سابقا
- اقتراحات الإكمال التلقائي قد تتعارض مع الخصوصية
- استخدام Attribute autocomplete للتحكم الكامل

## تعطيل Autocomplete في عنصر Input

يمكننا إيقاف الإكمال التلقائي لحقل إدخال واحد بإضافة autocomplete off إلى عنصر input.

```html
<input type="text"
autocomplete="off">
```

## شرح كود حقل الإدخال

أنشأنا عنصر input نصي وأضفنا إليه Attribute autocomplete بالقيمة off لمنع المتصفح من حفظ البيانات.

- استخدام input بنوع text
- إضافة Attribute autocomplete للتحكم
- تعيين القيمة off لتعطيل الذاكرة المؤقتة

## تعطيل Autocomplete لكامل نموذج Form

يمكننا أيضا تعطيل الإكمال التلقائي لكامل نموذج form لجميع الحقول دفعة واحدة.

```html
<form autocomplete="off">
  <!-- حقول الإدخال هنا -->
</form>
```

## شرح كود النموذج الشامل

عند تطبيق Attribute على عنصر form ترثها كافة حقول الإدخال الداخلية تلقائيا.

- تطبيق autocomplete off على form
- جميع الحقول الفرعية ترث هذه الخاصية
- توفير الجهد والرمز البرمي النظيف

## أفضل الممارسات والأمان

يفضل المطورون استخدام هذه التقنية في النماذج الحساسة لحماية خصوصية مستخدمي الويب.

- حماية نماذج تسجيل الدخول والحسابات
- منع تسريب البيانات الشخصية عبر المتصفح
- الالتزام بمعايير الأمان المتقدمة

## خلاصة الدرس

بهذا نكون قد انتهينا من شرح تعطيل autocomplete في HTML ونلتقي في الدرس القادم مع المدرب محمود عبدالحميد.

- تعلمنا استخدام Attribute autocomplete
- جربنا إيقافها لعنصر input منفرد
- تعلمنا تطبيقها لكامل عناصر form
- تابعوا معنا بقية دروس دورة HTML
