# التعليقات في لغة HTML

المصدر: https://www.w3schools.com/html/html_comments.asp

## مقدمة عن التعليقات في HTML

تعرف على أهمية كتابة التعليقات لتثبيت الملاحظات وتوثيق الشفرة المصدرية لصفحات الويب.

- لا تظهر تعليقات HTML داخل Web Browser
- تساعد في توثيق الشفرة المصدرية بوضوح
- تسهل قراءة الكود للمطورين الآخرين

## الصيغة الأساسية للتعليقات

تتطلب صيغة التعليق علامة تعجب في بداية Tag فقط دون نهايته.

```html
<!-- Write your comments here -->
```

## إضافة الملاحظات والتنبيهات

تتيح لك التعليقات وضع التنبيهات والتذكيرات ضمن الشفرة البرمجية.

```html
<!-- This is a comment -->

<p>This is a paragraph.</p>

<!-- Remember to add more information here -->
```

## إخفاء المحتوى مؤقتا

تستخدم التعليقات لإخفاء المحتوى المؤقت ومنع عرضه في المتصفح.

```html
  <p>This is a paragraph.</p>

<!-- <p>This is another paragraph 
  </p> -->

<p>This is a paragraph too.</p>
```

## استخدام التعليقات في اكتشاف الأخطاء

تساعد التعليقات في فحص الأخطاء وعزل أجزاء الكود لتسهيل عملية الـ debugging.

```html
  <p>This is a paragraph.</p>
<!--
<p>Look at this cool 
  image:</p>

<img border="0" src="pic_trulli.jpg" 
alt="Trulli">
-->
<p>This is a paragraph too.</p>
```

## إخفاء المحتوى ضمن السطر الواحد

يمكنك أيضا إخفاء أجزاء محددة في منتصف السطر البرمجي باستخدام التعليقات.

```html
  <p>This <!-- great text --> is a paragraph.</p>
```

## معاينة النتيجة في المتصفح

عرض النتيجة المرئية وتأكيد عدم ظهور التعليقات للمستخدم النهائي في المتصفح.

## خلاصة الدرس

خلاصة شاملة حول استخدام التعليقات وأهميتها الاحترافية في تطوير صفحات الويب.

- التعليقات تحسن تنظيم الكود وتوثيقه
- تستخدم لإخفاء العناصر بشكل مؤقت
- أداة أساسية في الـ debugging وفحص الأخطاء
