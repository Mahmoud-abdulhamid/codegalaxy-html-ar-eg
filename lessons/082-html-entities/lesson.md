# HTML Entities and Special Characters

المصدر: https://www.w3schools.com/html/html_entities.asp

## مقدمة حول HTML Entities

مرحبا بكم في درس HTML Entities وكيفية عرض الرموز المحجوزة في صفحة الويب.

- أهمية استخدام HTML Entities في صفحة الويب
- تجنب تعارض الرموز المحجوزة مع Tags
- عرض الرموز الخاصة بطريقة صحيحة وآمنة

## الرموز المحجوزة في HTML

استخدام رموز المقارنة قد يتسبب في تداخلها مع Tags في المتصفح.

- بعض الرموز محجوزة رسميا في لغة HTML
- علامات الأكبر والأصغر تتداخل مع Tags
- الحل هو استخدام Character Entities البديلة

## طريقة كتابة Entity Names و Numbers

يمكن استخدام أسماء أو أرقام الكيانات لعرض الرموز المحجوزة.

```html
&entity_name;
&#entity_number;
```

## تطبيق عملي لعرض الرموز الخاصة

كتابة الرموز الخاصة مثل علامة الأصغر باستخدام الكيانات.

```html
<p>To write: &lt; or &#60;</p>
```

## مفهوم Non-breaking Space

استخدام non-breaking space لمنع انقسام الكلمات في سطرين.

```html
<p>Hello&nbsp;World</p>
```

## الحفاظ على المسافات ومنع إزالتها

المتصفحات تحذف المسافات المتعددة، والحل هو استخدام الكيانات.

- المتصفح يحذف المسافات الزائدة تلقائيا
- استخدام الكيان لإضافة مسافات حقيقية
- التحكم الكامل في تنسيق النصوص والمسافات

## حساسية الحروف وحالات خاصة

أسماء الكيانات حساسة لحالة الحروف وتستخدم بحذر شديد.

- أسماء الكيانات حساسة لحالة الحروف Case sensitive
- استخدام non-breaking hyphen للشرطات الثابتة
- الالتزام بالمعايير الصحيحة لكتابة الكيانات

## شرح Combining Diacritical Marks

استخدام علامات التشكيل المركبة لإنتاج حروف ورموز جديدة.

- ما هي العلامات التشكيلية المركبة Diacritical Marks
- إضافة الحركات والزخارف للحروف اللاتينية
- توسيع نطاق الرموز المعروضة في صفحات الويب
