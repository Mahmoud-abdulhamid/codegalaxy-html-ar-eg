# HTML Attributes Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_attributes.asp

## مقدمة في HTML Attributes

مرحبا بكم في درس تحدي HTML Attributes، حيث سنتعلم كيفية استخدام الخصائص لتعزيز عناصر HTML.

- التعرف على أهمية Attributes في HTML
- كيفية إضافة معلومات إضافية للعناصر
- تطبيق عملي على تحدي Image Attributes

## مفهوم Attributes في HTML

تكتب Attributes داخل Start Tag وتتكون من اسم وقيمة لتعريف سلوك العنصر.

- تكتب Attributes داخل Start Tag
- تتكون من name و value
- تساعد المتصفح في معالجة العناصر

## تطبيق عملي على عنصر img

عنصر img يحتاج إلى Attributes مثل src و alt ليعمل بشكل صحيح.

```html
<img src="image.jpg" 
     alt="وصف الصورة">
<!-- هذا هو هيكل img -->
```

## شرح تفصيلي للخصائص

تضمن Attributes مثل src و alt تجربة مستخدم أفضل وتوافقية عالية.

- src يحدد مسار ملف الصورة
- alt يوفر نصا بديلا عند تعذر التحميل
- الالتزام بعلامات التنصيص ضروري

## أفضل الممارسات البرمجية

اتباع المعايير في كتابة Attributes يضمن كودا برمجيا احترافيا.

- استخدام الحروف الصغيرة للأسماء
- وضع القيم دائما بين علامات تنصيص
- التحقق من صحة الكود بانتظام
