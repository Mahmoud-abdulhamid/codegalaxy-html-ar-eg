# فهم HTML Elements و End Tags

المصدر: https://www.w3schools.com/html/html_challenges_elements.asp

## مقدمة في HTML Elements

مرحبا بكم في درس اليوم حول HTML Elements وكيفية بناء هيكل صفحات الويب بشكل احترافي.

- لغة HTML تعتمد على Elements لبناء المحتوى
- كل Element يتكون من Start Tag ومحتوى و End Tag
- فهم هذه القواعد أساسي لكل مطور ويب

## قواعد كتابة Elements

تتكون عناصر HTML من Start Tag والمحتوى ثم End Tag التي تحتوي على شرطة مائلة.

```html
<h1>هذا عنوان الصفحة</h1>
<p>هذه فقرة نصية.</p>
```

## تشريح الـ Elements

شرح تفصيلي لكيفية كتابة العناصر البرمجية باستخدام Start Tag و End Tag.

## مفهوم Empty Elements

Empty Elements أو Empty Elements لا تحتوي على محتوى ولا تتطلب End Tag.

```html
<p>سطر أول<br>سطر ثانٍ</p>
```

## أفضل الممارسات

أفضل الممارسات البرمجية تتطلب الالتزام بالمعايير القياسية لكتابة HTML.

- دائما أغلق التاجات التي لها محتوى
- استخدم الحروف الصغيرة لكتابة التاجات
- تأكد من ترتيب العناصر بشكل متداخل صحيح

## خاتمة الدرس

شكرا لمتابعتكم، لا تنسوا ممارسة كتابة الأكواد وتجربة التحديات المتاحة في الرابط.

- راجع مفاهيم Start Tag و End Tag
- تدرب على استخدام Empty Elements
- تابع الدورة لتتعلم المزيد عن Attributes
