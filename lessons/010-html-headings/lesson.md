# HTML Headings

المصدر: https://www.w3schools.com/html/html_headings.asp

## مقدمة حول HTML Headings

تعتبر العناوين أساسية لعرض العناوين الرئيسية والفرعية على صفحة الويب.

- تعريف Headings وعلاقتها بعرض العناوين
- أهمية تنظيم المحتوى للقارئ ومحركات البحث
- استخدام العناصر لإنشاء هرمية واضحة للمستند

## مستويات العناوين من h1 إلى h6

يتم تحديد العناوين باستخدام العناصر من h1 إلى h6 حسب الأهمية.

- العنصر h1 يمثل العنوان الأهم في الصفحة
- العنصر h6 يمثل العنوان الأقل أهمية
- المتصفحات تضيف مسافة بيضاء تلقائية قبل وبعد العنوان

## كتابة الكود الأساسي للعناوين

مثال عملي يوضح كتابة المستويات الستة للعناوين في HTML.

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

## معاينة المخرجات في المتصفح

معاينة شكل العناوين الستة عند عرضها داخل متصفح الويب.

## أهمية العناوين لمحركات البحث SEO

تستخدم محركات البحث العناوين لفهرسة هيكل محتوى صفحات الويب.

- مساعدة محركات البحث في فهرسة محتوى الصفحة
- تمكين المستخدمين من قراءة سريعة لهيكل المستند
- الحفاظ على التسلسل المنطقي من h1 إلى h3

## مثال عملي لهيكل مستند حقيقي

مثال عملي يوضح هيكلة دليل سفر باستخدام عناصر العناوين المتعددة.

```html
<h1>Travel Guide</h1>
<h2>Europe</h2>
<h3>France</h3>
<h3>Italy</h3>
<h2>Asia</h2>
<h3>India</h3>
<h3>Thailand</h3>
```

## التحكم في الحجم باستخدام Style

يمكن تحديد حجم أي عنوان باستخدام style attribute وخاصية font-size.

```html
<h1 style="font-size:60px;">
  Heading 1
</h1>
```

## أفضل الممارسات البرمجية والخلاصة

استخدم h1 مرة واحدة في الصفحة ولا تستخدم العناوين لتكبير النصوص فقط.

- استخدم عنصر h1 واحد فقط لكل صفحة ويب
- استخدم Headings للعناوين فقط وليس لتكبير النص
- راجع مرجع Tags للاستزادة وتطوير مهاراتك
