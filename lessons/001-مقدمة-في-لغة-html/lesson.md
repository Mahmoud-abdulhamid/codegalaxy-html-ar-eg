## التعلم بالتطبيق العملي

استخدام محرر Try it Yourself

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## مثال على كود HTML

هيكل صفحة HTML بسيطة
