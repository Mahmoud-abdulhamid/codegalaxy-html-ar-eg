## خرافة كود المتصفح

هل كودك سليم 100؟ المتصفح يحتاج معايير واضحة لعرض الصفحة بشكل صحيح.

- الاعتقاد الخاطئ: المتصفح يعرض أي كود بشكل سليم دائما.
- الحقيقة: المتصفح يحتاج هيكل معياري لتجنب تشويه العرض.
- الهدف: تعلم الأساس الحقيقي لبناء صفحات ويب احترافية.
- HTML هي حجر الأساس لأي موقع على الإنترنت.

## ما هي HTML؟

HTML هي اللغة القياسية لبناء هيكل صفحات الويب.

## هيكل صفحة HTML

هيكل صفحة HTML الأساسي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```
