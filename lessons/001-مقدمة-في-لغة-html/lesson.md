## ما هي لغة الـ HTML؟

تعريف الـ HTML ودورها في الويب

- HTML تعني HyperText Markup Language
- اللغة القياسية لهيكلة صفحات الويب
- تستخدم الـ Tags لتحديد العناصر
- ليست لغة برمجة بل لغة توصيف
- تحدد أماكن العناوين والفقرات والصور

## تشريح كود الـ HTML

شرح الهيكل الأساسي لصفحة HTML

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```
