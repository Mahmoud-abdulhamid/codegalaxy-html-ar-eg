## ما هي لغة HTML؟

مقدمة في لغة HTML: حجر الأساس لبناء صفحات الويب

- HTML اختصار لـ HyperText Markup Language
- اللغة القياسية لبناء صفحات الويب
- تستخدم لتحديد هيكل ومحتوى الصفحة
- سهلة التعلم وممتعة في التطبيق

## هيكل صفحة HTML

الهيكل الأساسي لكود HTML

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```
