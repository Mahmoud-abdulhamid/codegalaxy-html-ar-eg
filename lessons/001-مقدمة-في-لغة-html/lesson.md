# مقدمة في لغة HTML

المصدر: https://www.w3schools.com/html/default.asp

## خرافة المتصفح والكود

هل كودك سليم 100؟ المتصفح يحتاج لهيكل صحيح ليعرض المحتوى بشكل احترافي.

- المتصفح يحتاج لهيكل معياري ليعرض الصفحة بشكل صحيح
- فهم ترتيب الـ Tags يمنع تشويه العرض
- كتابة كود احترافي تبدأ من الأساسيات

## ما هي لغة HTML؟

HTML هي اللغة الأساسية لبناء صفحات الويب.

- HTML تعني HyperText Markup Language
- اللغة الأساسية لبناء هيكل صفحات الويب
- بدون HTML لا يمكن للمتصفح عرض المحتوى

## الهيكل الأساسي لصفحة HTML

الهيكل الأساسي لصفحة HTML.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## كيف يرى المتصفح الكود؟

المتصفح يترجم الـ HTML Tags إلى عناصر مرئية على الشاشة.
