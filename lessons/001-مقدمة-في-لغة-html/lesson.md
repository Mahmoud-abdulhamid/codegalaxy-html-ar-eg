# مقدمة في لغة HTML

المصدر: https://www.w3schools.com/html/default.asp

## الويب بيبدأ من هنا

HTML هي حجر الأساس لكل صفحات الويب

- الويب يعتمد بالكامل على HTML
- HTML هي اللغة القياسية لهيكلة صفحات الويب
- بناء موقعك الخاص يبدأ من هنا
- تعلم HTML ممتع وسهل للبداية

## أهلا بيكم في عالم الويب

تعريف HTML ودورها في الويب

- HTML تعني HyperText Markup Language
- لغة توصيف (Markup Language) وليست لغة برمجة
- المتصفح هو المترجم لكود HTML
- تستخدم لوصف هيكل الصفحة (عناوين، فقرات، روابط)

## الهيكل الأساسي لصفحة HTML

الهيكل الأساسي لصفحة HTML

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```
