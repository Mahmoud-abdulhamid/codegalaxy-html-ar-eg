## ما هي HTML؟

تعريف لغة HTML ودورها في الويب

- اختصار لـ HyperText Markup Language
- اللغة القياسية لبناء صفحات الويب
- الهيكل العظمي للموقع
- تحديد المحتوى للمتصفح

## أسلوب التعلم العملي

هيكل صفحة HTML بسيط

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## هيكل صفحة HTML

هيكل صفحة HTML الأساسي: <html>, <head>, و <body>

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```
