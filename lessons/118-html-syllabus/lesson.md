# الهيكل الأساسي لصفحات الويب باستخدام HTML

المصدر: https://www.w3schools.com/html/html_syllabus.asp

## مقدمة في لغة HTML

مرحبا بكم في درس الهيكل الأساسي لصفحات الويب باستخدام لغة HTML.

- لغة HTML هي حجر الأساس لبناء صفحات الويب
- لا تتطلب خبرة برمجية سابقة للبدء
- تعتمد على استخدام Tags و Elements لتنظيم المحتوى

## المفاهيم الأساسية

تتكون عناصر HTML من Start Tag والمحتوى ثم End Tag.

- Start Tag: Start Tag مثل <h1>
- End Tag: End Tag مثل </h1>
- Element: هو المكون الكامل من البداية للنهاية

## كتابة الهيكل الأساسي

يبدأ المستند بتعريف DOCTYPE HTML ثم Root Elementي html.

```html
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
```

## أقسام الصفحة

يحتوي head على البيانات الوصفية بينما يحتوي body على المحتوى المرئي.

```html
<body>
<h1>This is a Heading</h1>
<p>This is a paragraph.</p>
</body>
</html>
```

## معاينة النتيجة

هكذا تظهر العناصر في متصفح الويب بعد معالجة الكود.

## أفضل الممارسات

التزم دائما بإغلاق Tags وتنظيم الكود لسهولة القراءة.

- أغلق جميع Tags المفتوحة
- استخدم المسافات البادئة لتنظيم الكود
- اكتب الكود بأسلوب واضح ومنظم
