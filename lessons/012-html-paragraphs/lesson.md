# التعامل مع الفقرات والمسافات في HTML

المصدر: https://www.w3schools.com/html/html_paragraphs.asp

## مقدمة حول الفقرات في HTML

تعد الفقرات جزءا أساسيا من هيكلة المحتوى في صفحات الويب باستخدام HTML.

- الفقرة تبدأ دائما في سطر جديد
- المتصفح يضيف مسافات تلقائية حول الفقرة
- استخدام p لتعريف الفقرات

## استخدام العنصر p

يحدد العنصر p فقرة نصية ويقوم المتصفح بتنسيقها تلقائيا.

```html
<p>هذه هي الفقرة الأولى.</p>
<p>هذه هي الفقرة الثانية.</p>
```

## سلوك المتصفح مع المسافات

المتصفح يتجاهل المسافات الزائدة والأسطر الفارغة في كود HTML.

- لا يمكن الاعتماد على المسافات في الكود
- المتصفح يزيل المسافات الزائدة تلقائيا
- تغيير حجم الشاشة يؤثر على عرض النص

## الفواصل الأفقية باستخدام hr

يستخدم العنصر hr لإضافة فاصل أفقي بين عناصر الصفحة.

```html
<h1>عنوان رئيسي</h1>
<p>نص الفقرة.</p>
<hr>
<h2>عنوان فرعي</h2>
```

## إضافة سطر جديد بـ br

يستخدم العنصر br لكسر السطر داخل الفقرة دون إنشاء فقرة جديدة.

```html
<p>هذا سطر<br>وهذا سطر جديد.</p>
```

## النصوص المنسقة مسبقا بـ pre

العنصر pre يحافظ على التنسيق الأصلي للنص بما في ذلك المسافات والأسطر.

```html
<pre>
هذا النص سيظهر
كما هو تماماً.
</pre>
```

## خلاصة الدرس

مارس كتابة هذه العناصر لتتقن التحكم في تخطيط النصوص في صفحاتك.

- p للفقرات
- hr للفواصل الأفقية
- br لكسر السطر
- pre للنصوص المنسقة
