# إنشاء حقل البريد الإلكتروني في HTML

المصدر: https://www.w3schools.com/howto/howto_html_email_field.asp

## مقدمة حول حقول الإدخال

مرحبا بكم في درس إنشاء حقل البريد الإلكتروني باستخدام HTML.

- تعد حقول البريد الإلكتروني جزءا حيويا من نماذج الويب
- تسهل لغة HTML عملية جمع البيانات من المستخدمين
- التركيز على دقة البيانات المدخلة في صفحات الويب

## مفهوم input type email

استخدام input type email يخبر المتصفح بنوع البيانات المتوقعة.

- استخدام Attribute type مع القيمة email
- تفعيل التحقق التلقائي من تنسيق البريد
- تحسين تجربة المستخدم عبر المتصفحات الحديثة

## كتابة الكود البرمجي

ربط label مع input باستخدام Attribute for.

```html
<label for="email">Enter your email:</label>
<input type="email" id="email" 
  name="email">
```

## شرح Attributes المستخدمة

أهمية Attributes id و name في معالجة البيانات.

- Attribute id تربط label بالعنصر برمجيا
- Attribute name تستخدم لإرسال البيانات للخادم
- Attribute type تحدد نوع التحقق التلقائي

## التحقق التلقائي

المتصفح يتحقق تلقائيا من صحة تنسيق البريد الإلكتروني.

- التحقق يتم بدون كود إضافي من المطور
- يمنع إرسال البيانات غير الصحيحة
- يوفر تجربة مستخدم آمنة وسلسة

## أفضل الممارسات

استمر في التعلم وتجربة الأكواد بنفسك.

- راجع دروس HTML Forms للمزيد
- جرب الأكواد في بيئة تطوير حقيقية
- اهتم دائما بتجربة المستخدم

## خاتمة الدرس

شكرا لمتابعتكم، نلتقي في الدرس القادم.

- تم شرح إنشاء حقل البريد الإلكتروني
- تم توضيح أهمية التحقق التلقائي
- استمر في ممارسة البرمجة
