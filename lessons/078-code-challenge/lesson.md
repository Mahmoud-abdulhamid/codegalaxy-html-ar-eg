# HTML Computer Code Elements Challenge

المصدر: https://www.w3schools.com/html/html_challenges_computercode.asp

## مقدمة في عناصر الكود

مرحبا بكم في درس جديد من دورة HTML. اليوم سنتعلم كيفية عرض الأكواد البرمجية داخل صفحة الويب باستخدام Elements مخصصة لتحسين التجربة البصرية والدلالية للمستخدم.

- استخدام HTML لعرض النصوص التقنية
- أهمية Semantic Elements في الويب
- التعرف على العناصر المخصصة للكود

## العناصر البرمجية في HTML

توفر لغة HTML مجموعة من الـ Elements لتمييز نصوص الكود. مثل code لعرض مقاطع البرمجة، و kbd لإدخال لوحة المفاتيح، و samp لعرض مخرجات البرنامج. هذه الـ Tags تساعد الـ Web Browser على فهم المحتوى.

## كتابة الكود البرمجي

لننظر إلى هذا المثال. نستخدم Start Tag و End Tag لتغليف الكود. هذا يعطي شكلا مميزا للنص داخل الصفحة، ويسهل على الزائر تمييز أن هذا النص هو كود برمجي حقيقي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <code>
      x = 5;
      y = 6;
      z = x + y;
    </code>
  </body>
</html>
```

## تنسيق المخرجات

إذا أردنا عرض مخرجات الكود، نستخدم samp Element. هذا يعزز من دلالية الصفحة ويجعلها أكثر احترافية. لاحظ كيف نضع الـ Element داخل الـ body ليظهر بشكل صحيح في الـ Web Browser.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>النتيجة هي:</p>
    <samp>
      11
    </samp>
  </body>
</html>
```

## أفضل الممارسات

يجب دائما الحرص على استخدام الـ Tags المناسبة لكل نوع من المحتوى. لا تستخدم p لعرض الكود، بل استخدم code. هذا يساعد محركات البحث في فهم هيكل صفحة الويب بشكل أفضل.

- استخدم code للكود البرمجي
- استخدم kbd لمدخلات المستخدم
- استخدم samp لمخرجات النظام
- التزم بالهيكلة الدلالية

## خاتمة الدرس

بهذا نكون قد تعرفنا على كيفية تنسيق الأكواد في HTML. أدعوكم لتجربة هذه الـ Elements بنفسكم ومتابعة التحديات لتطوير مهاراتكم. كان معكم محمود عبدالحميد، وإلى اللقاء في درس قادم.

- راجع المصادر المرفقة
- طبق التحديات البرمجية
- استمر في التعلم
