# HTML Div Container Challenge

المصدر: https://www.w3schools.com/html/html_challenges_div.asp

## مقدمة حول div

مرحبا بكم في درس جديد من دورة HTML. اليوم سنتعرف على عنصر div، وهو حجر الزاوية في تنظيم صفحات الويب.

- عنصر div هو حاوية عامة للمحتوى
- يستخدم لتقسيم الصفحة إلى أجزاء منطقية
- لا يضيف تنسيقا خاصا بذاته
- يعتبر الأداة الأساسية في هيكلة الويب

## مفهوم الحاويات في HTML

يعمل عنصر div كحاوية تقوم بتجميع العناصر الأخرى مثل p أو h1، مما يسهل التحكم في تصميمها وتنسيقها لاحقا.

- تجميع العناصر داخل حاوية واحدة
- تسهيل تطبيق التنسيقات على مجموعة عناصر
- تحسين هيكلية الكود البرمجي
- دعم تنظيم المحتوى داخل الصفحة

## كتابة كود div

نستخدم Start Tag لفتح div، ثم نضع المحتوى، ونغلقه بـ End Tag لضمان عمل العناصر كوحدة واحدة.

```html
<div>
  <h1>عنوان الصفحة</h1>
  <p>هذه فقرة داخل div</p>
</div>
```

## تحليل هيكل الصفحة

لا يؤثر div على شكل النص بمفرده، بل يوفر بنية تحتية تجعل الصفحة قابلة للصيانة والتطوير وتساعد المتصفح في فهم الترتيب.

- لا يغير التنسيق الافتراضي
- يوفر بنية منطقية للمحتوى
- يسهل عملية الصيانة البرمجية
- يساعد المتصفح في فهم الهيكل

## أفضل الممارسات

استخدم div بحكمة ولا تفرط في استخدامه. استخدم العناصر الدلالية مثل section أو article عند الحاجة، واجعل div للتنسيق فقط.

- استخدم العناصر الدلالية أولا
- استخدم div للتنسيق العام
- حافظ على نظافة الكود
- تجنب التداخل المفرط للحاويات

## خاتمة وتطبيق

جربوا التحدي بأنفسكم عبر الرابط في الوصف. التطبيق العملي هو السبيل الأمثل لإتقان HTML. شكرا لمتابعتكم.

- قم بزيارة الرابط في الوصف
- طبق التحدي البرمجي بنفسك
- راجع مفاهيم div الأساسية
- استعد للدرس القادم
