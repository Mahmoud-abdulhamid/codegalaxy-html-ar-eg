المصدر: https://www.w3schools.com/html/html_symbols.asp

## مقدمة حول الرموز في لغة HTML

مرحبا بكم في درس رموز لغة HTML وكيفية عرض الحروف الخاصة غير الموجودة على لوحة المفاتيح.

- تستخدم لغة HTML لعرض الرموز الخاصة
- إضافة رموز غير موجودة على لوحة المفاتيح
- الاستفادة من Entities لعرض الحروف الخاصة

## مفهوم HTML Symbol Entities

نحتاج أحيانا لعرض رموز غير موجودة على لوحة المفاتيح باستخدام Entities في لغة HTML.

- الرموز غير الموجودة على لوحة المفاتيح
- استخدام الكيانات أو Entities
- إمكانية إضافتها بسهولة في صفحات الويب

## طرق كتابة الرموز والكيانات

يمكن استخدام اسم الكيان أو الرقم العشري أو الست عشري لإضافة الرموز بدقة.

```html
<p>I will display &euro;</p>
<p>I will display &#8364;</p>
<p>I will display &#x20AC;</p>
```

## شرح مثال عرض رمز اليورو

نعرض رمز اليورو باستخدام اسم الكيان والرقم العشري ورقم الستي عشري.

```html
&euro; is entity name
&#8364; is decimal
&#x20AC; is hex reference
```
