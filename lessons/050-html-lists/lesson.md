# HTML Lists

المصدر: https://www.w3schools.com/html/html_lists.asp

## مقدمة قوائم الوب

تعلم كيفية تجميع العناصر المرتبطة في صفحات الويب باستخدام Lists.

- تستخدم لغة HTML لإنشاء قوائم منظمة
- تساعد Lists المطورين على تجميع العناصر المرتبطة
- توجد أنواع مختلفة من القوائم في صفحات الويب

## القوائم غير المرتبة Unordered Lists

تبدأ Unordered Lists باستخدام ul وكل عنصر داخلها يبدأ بـ li.

- تعريف Unordered List باستخدام <ul>
- تحديد كل عنصر في القائمة باستخدام <li>
- تظهر العناصر افتراضيا بنقاط دائرية سوداء

## كود القائمة غير المرتبة

مثال عملي لكتابة Unordered List في HTML.

```html
<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
```

## القوائم المرتبة Ordered Lists

تستخدم Ordered Lists مع ol و li وتظهر مرقمة افتراضيا.

```html
<ol>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ol>
```

## معاينة القائمة المرتبة

صورة معاينة القائمة المرتبة في المتصفح.

## قوائم الوصف Description Lists

تعريف Description Lists باستخدام dl و dt و dd.

```html
<dl>
  <dt>Coffee</dt>
  <dd>- black hot drink</dd>
  <dt>Milk</dt>
  <dd>- white cold drink</dd>
</dl>
```
