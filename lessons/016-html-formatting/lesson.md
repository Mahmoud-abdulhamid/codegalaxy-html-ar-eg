# HTML Text Formatting Elements

المصدر: https://www.w3schools.com/html/html_formatting.asp

## مقدمة عن تنسيق النصوص في HTML

تحتوي لغة HTML على عناصر مخصصة لتنسيق النصوص بمعان خاصة.

- تستخدم لغة HTML لتنسيق النصوص بكفاءة عالية
- توفر عناصر خاصة لإبراز الأهمية والدلالة
- تساعد في تحسين تجربة القراءة وتوضيح المحتوى

## عناصر تغميق الخط b و strong

العناصر b و strong تستخدم لتغميق النص بأساليب مختلفة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <b>This text is bold</b>
    <strong>Important!</strong>
  </body>
</html>
```

## عناصر الخط المائل i و em

العناصر i و em تعرض النص بخط مائل لدلالات مختلفة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <i>This is italic</i>
    <em>Emphasized text</em>
  </body>
</html>
```

## عناصر التصغير والتحديد small و mark

استخدام small لتصغير النص و mark لتسليط الضوء عليه.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <small>Smaller text</small>
    <mark>Highlighted milk</mark>
  </body>
</html>
```

## عناصر الحذف والإضافة del و ins

العنصر del يحذف نصا بخط يتوسطه، و ins يضيف خطا تحته.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>Color <del>blue</del> <ins>red</ins></p>
  </body>
</html>
```

## النصوص السفلية والعلوية sub و sup

العناصر sub و sup تستخدم للنصوص السفلية والعلوية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>H<sub>2</sub>O</p>
    <p>E=MC<sup>2</sup></p>
  </body>
</html>
```

## خلاصة الدرس

خلاصة درس تنسيق النصوص في HTML وكيفية توظيفها بكفاءة.

- استخدام b و strong لتغميق الخط
- استخدام i و em لإمالة النصوص
- استخدام del و ins للحذف والإضافة
- استخدام sub و sup للنصوص السفلية والعلوية
