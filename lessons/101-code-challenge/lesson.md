# HTML SVG Graphics Challenge

المصدر: https://www.w3schools.com/html/html_challenges_svg.asp

## مقدمة في رسومات SVG

مقدمة حول دمج رسومات SVG داخل صفحات الويب باستخدام HTML.

- تقنية SVG تتيح رسم أشكال هندسية متجهة
- تتميز SVG بدقتها العالية عند التكبير
- تندمج عناصر SVG مباشرة داخل كود HTML
- تستخدم في بناء الرسوم البيانية والأيقونات

## المفاهيم الأساسية لـ SVG

شرح العناصر الأساسية المستخدمة في تعريف رسومات SVG.

- العنصر <svg> هو الحاوية الرئيسية للرسومات
- نستخدم <rect> لرسم المستطيلات
- نستخدم <circle> لرسم الدوائر
- تحدد Attributes Attributes أبعاد وموقع كل شكل

## هيكلية كود SVG

هيكلية كود SVG الأساسي داخل مستند HTML.

```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" 
  stroke="black" 
  stroke-width="3" 
  fill="red" />
</svg>
```
