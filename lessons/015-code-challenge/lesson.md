# HTML Styles Code Challenge

المصدر: https://www.w3schools.com/html/html_challenges_styles.asp

## مقدمة حول HTML Styles

مرحبا بكم في درس HTML Styles حيث نتعلم التحكم في مظهر العناصر باستخدام Attribute المسمى style.

- استخدام style Attribute لتنسيق العناصر
- تغيير الألوان والخطوط والأحجام
- فهم كيفية دمج CSS داخل HTML
- تطبيق التحديات البرمجية العملية

## مفهوم الـ Style Attribute

يتم إضافة style Attribute داخل Start Tag لتحديد خصائص التصميم مثل اللون أو الحجم.

- البنية: <tag style="property: value">
- تستخدم لتغيير لون النص عبر color
- تستخدم لتغيير حجم الخط عبر font-size
- تستخدم لتغيير لون الخلفية عبر background-color

## تطبيق عملي على Style

مثال يوضح تطبيق style على عناصر body و h1 لتغيير الألوان.

```html
<body style="background-color: powderblue;">
<h1 style="color: blue;">
هذا عنوان ملون
</h1>
<p style="color: red;">
هذه فقرة بنص أحمر
</p>
</body>
```

## قواعد كتابة الـ Styles

قواعد كتابة CSS داخل HTML تتطلب دقة في استخدام الفواصل والنقاط الرأسية.

## أفضل الممارسات

استخدام style Attribute مفيد للتعلم، ولكن يفضل استخدام ملفات CSS خارجية للمشاريع الكبيرة.

- استخدم style للنماذج السريعة
- افصل CSS في ملفات خارجية للمشاريع الكبيرة
- حافظ على نظافة الكود وتنسيقه
- جرب تغيير القيم لرؤية النتائج فورا

## خلاصة الدرس

قم بتجربة الأكواد وحل التحديات لتعزيز مهاراتك في HTML و CSS.

- تمت تغطية style Attribute
- تم شرح كيفية كتابة الخصائص والقيم
- تم توضيح أهمية الدقة في الـ Syntax
- شجعنا على التطبيق العملي المستمر
