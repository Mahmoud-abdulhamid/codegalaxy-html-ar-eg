# التعامل مع HTML Comments

المصدر: https://www.w3schools.com/html/html_challenges_comments.asp

## مقدمة حول HTML Comments

تعد Comments جزءا أساسيا في HTML لتنظيم وتوثيق الكود البرمجي.

- تستخدم Comments لإضافة ملاحظات للمطورين
- لا تظهر هذه النصوص في Web Browser
- تساعد في فهم هيكل الكود المعقد
- تسهل عملية صيانة وتطوير صفحات الويب

## قواعد كتابة Comments

تكتب Comments باستخدام الصيغة <!-- Comment text --> في أي مكان داخل الكود.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <!-- هذا تعليق لا يظهر -->
    <p>هذا نص يظهر في المتصفح</p>
  </body>
</html>
```

## تطبيق عملي للتعليقات

استخدام التعليقات لتقسيم وتوثيق أقسام صفحة الويب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <!-- بداية قسم الترويسة -->
    <h1>عنوان الصفحة</h1>
    <!-- نهاية قسم الترويسة -->
  </body>
</html>
```

## استخدام التعليقات في Debugging

التعليقات أداة قوية لتعطيل الأكواد مؤقتا أثناء الاختبار.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <!-- <p>هذا الكود معطل حالياً</p> -->
    <p>هذا الكود يعمل بشكل طبيعي</p>
  </body>
</html>
```

## أفضل الممارسات

نصيحة: لا تضع معلومات حساسة أو سرية داخل التعليقات.

- لا تضع كلمات مرور في التعليقات
- اكتب تعليقات واضحة ومختصرة
- استخدمها لتنظيم الأقسام الكبيرة
- احذف التعليقات غير الضرورية قبل النشر

## خاتمة الدرس

طبق ما تعلمته الآن عبر الرابط في الوصف لتطوير مهاراتك.

- راجع مفاهيم HTML Comments
- قم بزيارة الرابط المرفق للتطبيق
- استمر في ممارسة البرمجة يوميا
- نراكم في الدرس القادم
