# HTML Tables Structure Challenge

المصدر: https://www.w3schools.com/html/html_challenges_tables.asp

## مقدمة حول الجداول في HTML

مرحبا بكم في درس جديد من دورة HTML. اليوم سنتعلم كيفية بناء الجداول باستخدام لغة الويب، وهي مهارة أساسية لتنظيم البيانات بشكل احترافي ومنسق داخل صفحة الويب.

- الجداول وسيلة قوية لعرض البيانات
- تعتمد الجداول على هيكل هرمي من العناصر
- تساعد في تحسين تجربة المستخدم

## العناصر المكونة للجدول

لإنشاء جدول نستخدم Element يسمى table. داخل هذا الـ Element نضع صفوفا باستخدام tr، وداخل كل صف نضع خلايا. الخلايا إما أن تكون عنوانا باستخدام th أو بيانات عادية باستخدام td.

- table: العنصر الحاوي للجدول
- tr: لتعريف صف داخل الجدول
- th: لتعريف خلية العنوان
- td: لتعريف خلية البيانات

## كتابة هيكل الجدول

لنشاهد مثالا عمليا. نبدأ بـ table، ثم نضيف tr للرأس، وداخله نضع th لعناوين الأعمدة. هذا الترتيب يضمن ظهور البيانات بشكل سليم ومنظم لكل من يزور صفحة الويب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <table>
      <tr>
        <th>الاسم</th>
        <th>العمر</th>
      </tr>
    </table>
  </body>
</html>
```

## إضافة بيانات الجدول

الآن نضيف صفا جديدا باستخدام tr لإدخال البيانات الفعلية. نستخدم td لكل خلية. لاحظ كيف نغلق كل Start Tag بـ End Tag مناسب لضمان صحة الكود وتجنب أي أخطاء برمجية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <tr>
      <td>محمود</td>
      <td>30</td>
    </tr>
  </body>
</html>
```

## أفضل الممارسات

من أهم النصائح هي الحرص على إغلاق جميع الـ Tags بشكل صحيح. كما يفضل استخدام التنسيق المنظم للكود ليسهل قراءته وتعديله لاحقا. هذه القواعد ترفع من جودة مشاريع الويب الخاصة بكم.

- أغلق دائما جميع الـ Tags
- استخدم مسافات بادئة لتنظيم الكود
- تأكد من مطابقة عدد الـ td مع الـ th
- استخدم الـ Tags المناسبة لكل محتوى

## خاتمة وتحدي

بهذا نكون قد تعرفنا على هيكل الجداول. أدعوكم لتجربة هذا التحدي بنفسكم عبر الرابط الموجود في وصف الفيديو. التطبيق العملي هو السبيل الأمثل لإتقان مهارات البرمجة بشكل فعال ومستمر.

- راجع الأكواد التي كتبناها اليوم
- قم بزيارة رابط المصدر للتحدي
- مارس كتابة الجداول بنفسك
- استمر في التعلم مع CodeGalaxy
