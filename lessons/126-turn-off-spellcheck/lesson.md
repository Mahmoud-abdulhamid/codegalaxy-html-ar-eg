# تعطيل خاصية Spellcheck في نماذج HTML

المصدر: https://www.w3schools.com/howto/howto_html_spellcheck_disable.asp

## مقدمة حول خاصية Spellcheck

مرحبا بكم في درس اليوم حول كيفية تعطيل خاصية spellcheck في نماذج HTML لتحسين تجربة المستخدم.

- تفعيل أو تعطيل التصحيح الإملائي في المتصفح
- التحكم في تجربة المستخدم داخل حقول الإدخال
- استخدام Attribute spellcheck في عناصر HTML

## مفهوم spellcheck في المتصفح

المتصفحات تقوم تلقائيا بتحديد الكلمات التي تبدو خاطئة إملائيا بخط أحمر، وهو ما يمكن التحكم فيه برمجيا.

- المتصفح يقوم بالتصحيح التلقائي افتراضيا
- الخط الأحمر يظهر تحت الكلمات غير الصحيحة
- يمكن للمطورين التحكم في هذا السلوك

## تعطيل spellcheck في input و textarea

نستخدم Attribute spellcheck="false" لتعطيل التصحيح الإملائي في عناصر الإدخال.

```html
<input type="text" 
  spellcheck="false">

<textarea 
  spellcheck="false">
</textarea>
```

## تطبيق spellcheck على مستوى النموذج

يمكن تطبيق Attribute spellcheck="false" على عنصر <form> لتعطيل التصحيح في جميع الحقول بداخله.

```html
<form spellcheck="false">
  <!-- جميع الحقول هنا -->
  <!-- ستكون بدون تصحيح -->
</form>
```

## ملاحظات وأفضل الممارسات

تذكر أن spellcheck Attribute عالمية يمكن استخدامها مع عناصر HTML متنوعة.

- spellcheck هي Attribute عالمية (Global Attribute)
- يمكن استخدامها مع عناصر قابلة للتحرير
- راجع توثيق HTML Form لمزيد من التفاصيل

## خلاصة الدرس

شكرا لمتابعتكم. جربوا الأكواد بأنفسكم وتابعوا الدورة لمزيد من المهارات في HTML.

- تم شرح كيفية تعطيل التصحيح الإملائي
- تم تطبيق Attribute على مستوى الحقل والنموذج
- شجعنا على الممارسة العملية للأكواد
