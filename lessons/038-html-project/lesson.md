# HTML Project Personal Page

المصدر: https://www.w3schools.com/html/html_project_bio.php

## مقدمة المشروع الشخصي

نبدأ اليوم بناء أول مشروع حقيقي وهو صفحة سيرة ذاتية شخصية باستخدام HTML.

- بناء أول مشروع HTML شخصي بالكامل
- إنشاء سيرة ذاتية مع نصوص وقوائم
- تطبيق المهارات المكتسبة في بيئة العمل الحية

## مكونات المشروع الشخصي

يحتوي المشروع على نصوص منسقة، وقوائم، وصور، وروابط تشعبية.

- كتابة نصوص وسير ذاتية منسقة بدقة
- إدراج قوائم منظمة داخل الصفحة
- دمج الصور والروابط التشعبية الفعالة

## هيكل صفحة الويب الأولى

نكتب الكود في محرر النصوص ويبدأ المستند بتعريف DOCTYPE HTML.

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Bio</title>
</head>
<body>
```

## إضافة المحتوى المرئي

نضيف العنوان الرئيسي h1 والنصوص التوضيحية p داخل قسم body.

```html
  <h1>About Me</h1>
  <p>Hello, I am a web developer.</p>
  <p>Learning HTML step-by-step.</p>
</body>
</html>
```

## نظام تقييم المشروع

يقسم المشروع إلى خمس خطوات رئيسية ولكل خطوة معيار نجاح خاص.

- المشروع مقسم إلى 5 مراحل أساسية
- لكل خطوة معيار نجاح واجتياز خاص
- تحقيق التقدم التدريجي نحو الاحتراف

## التحقق من الكود والنقاط

انقر على Check code في كل خطوة للتحقق من تقدمك وكسب نقاط XP.

- استخدم زر Check code للتحقق الفوري
- تأكد من صحة النتائج قبل الانتقال للخطوة التالية
- اجمع نقاط XP بالكامل مع إنجاز المهام

## خلاصة الدرس العملي

التطبيق العملي هو السبیل الأفضل لفهم HTML وتعزيز مهاراتك البرمجية.

- التطبيقات العملية تثبت المعلومات بذهنك
- جرب كتابة الأكواد بنفسك في محرر النصوص
- تابع معنا الدروس القادمة لاستكمال المهارات
