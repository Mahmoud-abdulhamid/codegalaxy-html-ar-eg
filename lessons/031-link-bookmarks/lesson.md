# HTML Links - Create Bookmarks

المصدر: https://www.w3schools.com/html/html_links_bookmarks.asp

## مقدمة عن Bookmarks في صفحات الويب

تستخدم لغة HTML لإنشاء Bookmarks تساعد القراء على الانتقال السريع بين أجزاء صفحة الويب.

- تستخدم روابط HTML لإنشاء Bookmarks في صفحات الويب الطويلة
- تتيح للقراء القفز المباشر إلى أجزاء محددة داخل المستند
- تحسن تجربة المستخدم وسهولة التنقل في الموقع

## آلية العمل والمفاهيم الأساسية

تعتبر Bookmarks مفيدة للصفحات الطويلة ويتم إنشاؤها عبر خطوتين أساسيتين.

- تعتبر Bookmarks أدوات مثالية لصفحات الويب ذات المحتوى الطويل
- تتطلب العملية إنشاء الـ Bookmark أولا ثم ربطه
- يؤدي النقر فوق الرابط إلى التمرير التلقائي نحو الموضع المطلوب

## إنشاء Bookmark باستخدام id attribute

نستخدم id attribute لإنشاء Bookmark داخل العنصر المستهدف.

```html
<h2 id="C4">Chapter 4</h2>
```

## ربط الصفحة بنفس الـ Bookmark

نضيف رابطا تشعبيا داخل نفس الصفحة للوصول إلى الفصل الرابع.

```html
<a href="#C4">Jump to Chapter 4</a>
```

## الربط بـ Bookmark في صفحة أخرى

يمكنك إضافة روابط تؤدي إلى Bookmarks موجودة في صفحات ويب أخرى.

```html
<a href="html_demo.html#C4">
Jump to Chapter 4
</a>
```

## معاينة النتيجة المرئية في المتصفح

صورة توضح معاينة الـ Bookmarks وكيفية عملها في متصفح الويب.

## أفضل الممارسات البرمجية

تأكد من فريدية قيم الـ id داخل صفحة الويب لتجنب أي أخطاء في التنقل.

- يجب أن تكون قيمة id فريدة لكل عنصر في الصفحة الواحدة
- استخدم علامة الحجز # قبل اسم الـ id في الـ href
- اختبر الروابط جيدا للتأكد من سلاسة التمرير والانتقال

## خلاصة الدرس والخطوات القادمة

خلاصة درس HTML Links وCreate Bookmarks مع المهندس محمود عبدالحميد.

- تعلمنا إنشاء وتفعيل Bookmarks في HTML
- استخدمنا id attribute والرمز # للربط الفعال
- نتطلع لرؤيتكم في الدرس القادم من دورة HTML
