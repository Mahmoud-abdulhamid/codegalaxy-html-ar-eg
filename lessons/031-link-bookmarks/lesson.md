# HTML Links - Create Bookmarks

المصدر: https://www.w3schools.com/html/html_links_bookmarks.asp

## مقدمة عن Bookmarks

تستخدم HTML links لإنشاء Bookmarks والانتقال إلى أجزاء محددة في الصفحة.

- أهمية Bookmarks في صفحات الويب الطويلة
- الانتقال السريع إلى أقسام محددة
- تحسين تجربة المستخدم بشكل ملحوظ

## فكرة عمل Bookmarks

تكون Bookmarks مفيدة في الصفحات الطويلة لتسهيل التنقل.

- تفيد في الصفحات ذات المحتوى الطويل
- تتطلب إنشاء الموضع أولا ثم ربطه
- تقوم بالتمرير تلقائيا عند النقر

## إنشاء Bookmark باستخدام id

نستخدم id attribute لإنشاء Bookmark داخل عنصر معين.

```html
<h2 id="C4">Chapter 4</h2>
```

## الرابط داخل نفس الصفحة

نضيف رابطا داخليا باستخدام href مع علامة الشباك وقيمة id.

```html
<a href="#C4">Jump to Chapter 4</a>
```

## الرابط إلى صفحة أخرى

يمكن ربط Bookmark في صفحة أخرى بتحديد اسم الملف ثم id.

```html
<a href="html_demo.html#C4">Jump to Chapter 4</a>
```

## معاينة النتيجة المرئية

معاينة مظهر الانتقال إلى Bookmarks في متصفح الويب.

## أفضل الممارسات

تأكد من فريدة قيم id داخل نفس الصفحة لضمان سلامة العمل.

- يجب أن تكون قيمة id فريدة في الصفحة
- استخدام الرمز # في attribute من نوع href
- اختيار أسماء معبرة للروابط والمواقع

## خلاصة الدرس

خلاصة درس إنشاء Bookmarks والروابط الداخلية والخارجية.

- تعلمنا إنشاء Bookmarks عبر id attribute
- ربط الصفحات محليا وخارجيا بنجاح
- ندعوكم لتجربة الأكواد بأنفسكم
