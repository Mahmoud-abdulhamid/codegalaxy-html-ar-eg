# إنشاء عنصر Color Picker في صفحات الويب باستخدام HTML

المصدر: https://www.w3schools.com/howto/howto_html_colorpicker.asp

## مقدمة الدرس

مرحبا بكم في درس إنشاء عنصر Color Picker باستخدام لغة HTML لبناء صفحات الويب.

- تعلم كيفية إنشاء أداة اختيار الألوان
- استخدام عناصر HTML التفاعلية الحديثة
- تحسين تجربة المستخدم في الويب

## المفاهيم الأساسية

نستخدم input type color لإنشاء أداة اختيار الألوان التفاعلية بسهولة.

- استخدام input tag لإنشاء الحقول التفاعلية
- تحديد type color لعنصر اختيار الألوان
- توفير واجهة رسومية لاختيار درجات الألوان

## كتابة الكود البرمجي الجزء الأول

نكتب label tag لتوضيح الغرض من أداة اختيار الألوان للمستخدم.

```html
<label for="favcolor">
  Select your favorite color:
</label>
```

## كتابة الكود البرمجي الجزء الثاني

نضيف input type color ونحدد الخاصية value لاختيار اللون الافتراضي.

```html
<input 
  type="color" 
  id="favcolor" 
  value="#ff0000">
```

## شرح قيم الألوان HEX

يجب استخدام قيم HEX داخل الخاصية value والقيمة الافتراضية هي الأسود.

- استخدام HEX values داخل الخاصية value
- القيمة الافتراضية هي اللون الأسود favcolor
- الرمز #000000 يمثل اللون الأسود تماما

## أفضل الممارسات البرمجية

دمج label مع input يضمن وصول مستخدمي قارئات الشاشة للمحتوى بفعالية.

- ربط label مع id الخاص بـ input
- تحسين إمكانية الوصول في صفحات الويب
- الالتزام بمعايير لغة HTML الحديثة

## خلاصة الدرس

تعرفنا على كيفية إنشاء عنصر Color Picker وتعيين القيم السداسية HEX بنجاح.

- إنشاء Color Picker باستخدام HTML
- استخدام قيم HEX لتحديد الألوان
- تطبيق أفضل الممارسات البرمجية
